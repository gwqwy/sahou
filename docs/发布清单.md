# GitHub 发布操作清单（内部备忘，发布前可删除本文件）

本文件夹是**可直接推送的仓库根**：已含源码、文档、示例、测试、根 README、.gitignore，
并已 `git init` 且完成本地提交。**尚未连接任何远程仓库、尚未发布。**

## 已就绪、无需再动的

- **许可证**：根目录 `LICENSE` 已是 **MIT**（版权归 "Sa (卅) Language Authors"，如想署自己的名字，
  把第一行 Copyright 改成你的名字/组织即可），README 的许可证一节已指向它。
- **图标**：`assets/icon.svg`（印章红圆角方块应用图标）与 `assets/logo.svg`（透明底字标）。
  想在 GitHub 仓库页显示社交卡片图，可在仓库设置 → Social preview 上传 icon.svg 导出的 PNG。

## 发布前唯一建议决定的事

1. **Go 模块路径（可选）**：`go.mod` 里当前是 `module sahou`。本地构建没问题，
   但发布后若希望别人 `go install github.com/你的用户名/sahou@latest`，需要改成真实路径：
   把 `go.mod` 的模块名改为 `github.com/你的用户名/sahou`，并全库把 import 前缀
   `"sahou/internal/...` 改为 `"github.com/你的用户名/sahou/internal/...`（internal/ 下所有 .go 文件）。
   需要的话我可以代做——告诉我最终的仓库地址即可。
2. **仓库语言设置**：GitHub 会按文件统计把本仓库识别为 Go，无需配置。

## 可选但建议

- 语言名是「卅」（读音 sa）；工具/命令名保持 sahou（`sahou.exe`、`sahou run/build/...`）——这是有意的命名约定：语言叫卅，工具链叫 sahou。
- 在 GitHub 仓库设置里开 Issues。
- 成品不入库：`sahou.exe` / `sahou.wasm` 挂 **GitHub Releases**（构建：`go build -o sahou.exe .`，或先 `bash tests/wasm.sh` 再构建；wasm 单独要的话 `sahou.exe 导出运行时` 能从 exe 里导出）。
- 克隆本仓库后从源码构建：先 `bash tests/wasm.sh`（生成根目录 `sahou.wasm`，构建 exe 时要内嵌它），再 `go build -o sahou.exe .`。
- 若仓库改用英文或双语，`docs/` 目前是纯中文，建议在 README 开头加一行英文简介。
- 发布前删除本文件（或留着当内部清单也行，无敏感内容）。
