# 卅· 纯 卅 标准库包

> 本文对应 `stones/` 目录下的十个标准库包。它们**只用 卅本身**实现，
> 是"自举分层"的示范：宿主原语（Go/JS 各一份）之上，逻辑只写一份 卅。

## 分层结构

```
第一层 宿主原语：核心内置函数（写作时 29 个，现为 30 个）+ 网络/页面/随机/时间/数学/编码/系统 模块（Go 与 JS 各一份）
第二层 纯 卅 包：stones/ 下的 算术库/文本库/游戏库/中文数字/集合运算/统计库/单位换算/进制库/几何库/算法库（只有这一份实现）
```

第二层的包在解释器（`sahou run`）和浏览器（`sahou build` 打包）里行为一致，
因为它们就是普通用户模块——打包器本来就会递归打包 stones/ 目录。

## 十个包

| 包 | 成员 | 说明 |
|---|---|---|
| 算术库 | 最大公约数、最小公倍数、约分、是否质数、质因数分解、取整数值、阶乘 | 精确整数算法 |
| 文本库 | 是否回文、居中、左对齐、统计字符、分行、连接行、蛇形命名、驼峰命名、前导零 | 文本处理 |
| 游戏库 | 掷骰子、洗牌、抽奖、抛硬币 | 组合 随机 模块原语 |
| 中文数字 | 到中文、到数 | 整数 0..9999 的数 ↔ 中文互转 |
| 统计库 | 平均值、中位数、众数、极差、方差、标准差 | 基础统计量（总体口径） |
| 单位换算 | 长度换算、重量换算、数据换算、温度换算 | 换算系数表（字典）+ 温度公式 |
| 进制库 | 到进制、自进制、到/自二进制、到/自十六进制、到八进制 | 2 到 36 进制互转 |
| 几何库 | 圆面积/周长、矩形/三角形/梯形面积、海伦面积、勾股斜边、两点距离 | 公式 + 参数校验 |
| 算法库 | 冒泡/插入/快速排序、线性/二分查找、是否已排序 | 看得见过程的教学实现 |

## 用法

```saho
用 "算术库" 引入
用 "文本库" 引入

print(算术库.最大公约数(12, 18))       # 6
print(文本库.是否回文("上海自来水来自海上"))  # 真
print(统计库.平均值([95, 58, 72, 88, 60]))   # 74.6
print(单位换算.温度换算(37, "摄氏", "华氏"))  # 98.6
print(进制库.到十六进制(255))                # FF
print(几何库.勾股斜边(3, 4))                 # 5
print(算法库.快速排序([5, 2, 8, 1]))         # [1, 2, 5, 8]
```

> **发布版自带**：这十个包都**内嵌在 `sahou.exe` 里**——`用 "包名" 引入` 不需要安装就能用
> （磁盘 stones/ 里的同名包优先，便于本地覆盖）；`sahou 装 包名` 可把包源码取出到 stones/
> 好修改学习；`sahou stones` 列出全部自带包。

- **查找规则**：从脚本所在目录逐级向上找 `stones/`（同 node_modules 惯例），
  所以仓库子目录里的程序也能用到根目录 stones/ 下的包；`sahou build` 同样支持。
- **安装到自己的项目**：`sahou 装 <stones/算术库 的路径>`，随后在项目任何子目录里引入。

## 运行示例

仓库自带的完整演示：`examples/pkgdemo/演示.saho`（覆盖全部十个包）。

测试：`bash tests/packages.sh`（解释器与转译双侧、向上查找、装命令、模块隔离、循环引入）。
