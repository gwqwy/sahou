# 卅语言 · 设计决策简报（唯一事实来源）

## 1. 语言定位

- 名称：中文 **卅**，英文 **卅**。"卅"是"三十"的古体字，三横一竖四画写完——比"蟒蛇"两个字更小、更简单；源文件后缀为 **`.saho`**。
- 一句话定位："比 Python 更简单一点的入门语言"——保留 Python 的动态、灵活、可读，砍掉新手最容易踩坑的部分。
- 目标用户：零基础初学者、中小学编程教育、从自然语言过渡到代码的人。
- 非目标：高性能计算、大型工程、并发编程（这些留到后续版本）。
- 实现路线：v1 为**Go 实现的树遍历解释器**（独立可执行文件 `sahou`，不依赖任何其他语言运行时），v2 考虑字节码 VM。

## 2. 核心设计决策（共 10 条）

### D1 用 `end` 关键字收尾，不用缩进和花括号
Python 的缩进块是新手最大错误来源（混用空格/Tab、缩进层级错）。卅 用 `end` 收尾（参考 Lua/Ruby），块结构一目了然，任意缩进、空格 Tab 混用都不报错。
**v2 增补**：熟悉 Java/C 的用户也可以用花括号 `{ }` 收尾块（两种风格完全等价，同一块内不要混用）；缩进依然只是排版。

```
if x > 3
    print("大")
else
    print("小")
end
```

### D2 双语关键字：中文英文都能写
每条语句提供等价的中文关键字，程序可以全中文书写，也可以全英文，或混用。

| 英文 | 中文 | | 英文 | 中文 |
|---|---|---|---|---|
| `if` | `如果` | | `fn` | `函数` |
| `elif` | `又如` | | `return` | `返回` |
| `else` | `否则` | | `for` | `遍历` |
| `while` | `当` | | `in` | `于` |
| `end` | `完毕` | | `and` | `并且` |
| `true` | `真` | | `or` | `或者` |
| `false` | `假` | | `not` | `非` |
| `null` | `空值` | | `let` | `设` |
| `try` | `尝试` | | `catch` | `接住` |
| `use` | `用` | | `import` | `引入` |

（`let/设` 是可选的变量赋值前缀，写不写都可以；`用 "模块名" 引入` 是 v2 的模块引入语句，`引入` 可省略。）

以上共 **23 个关键字**（v1 为 18 个；v2 新增 `用/use`、`引入/import`；v4 新增 `格子/cell`、`跳出/break`、`继续/continue`）。v1 的 18 个是一个不多、一个不少的完整清单。
`break`/`continue`（跳出/继续）、`class`、`import`、`raise`、`finally` 均不在其中：
提前结束循环用"布尔标志 + `当`"，抛错用内置函数 `抛出("消息")`。
本表与《02-语言规范.md》2.6 节的完整双语对照表逐行一致。

### D3 用户只看到一个"数"类型
Python 里 `int / float / 10 / 10.0 / 精度` 是新手噩梦。卅 只有一种**数**（number）：内部自动按需用整数或小数表示，用户永远写 `10`、`3.5`，`10 == 10.0` 成立，`10 / 3` 得 `3.3333...`（除法永远是真除法）。整数精确运算在内部仍然保证（计数、索引不出错）。

### D4 只有 5 种数据类型
数（number）、文本（string）、列表（list）、字典（dict）、布尔（bool），外加一个空值（null/空值）。没有元组、集合、字节、复数。需要集合语义时用列表 + `列表.去重()`。没有类（class）——v1 用字典 + 函数组合表达结构化数据。

### D5 函数是一等公民，但定义方式只有一种
```
函数 加(a, b)
    返回 a + b
完毕
```
没有 lambda、没有装饰器、没有方法重载。匿名函数用一个语法：`函数(参数) => 表达式`。

### D6 字符串插值代替拼接的心智负担
`"你好, {名字}!"` 花括号内可以是任意表达式。`+` 也能拼接文本，但推荐插值。

### D7 循环只有两种
`for x 于 列表` 和 `while 条件`。没有 `range` 的三参数形式——提供内置函数 `从a到b(步长)` 返回列表，或直接遍历列表。没有列表推导式（这是 Python 语法中最难教的部分之一），需要新列表就写显式循环。

### D8 错误处理极简：尝试/接住
```
尝试
    危险操作()
接住 错误信息
    print("出错了: {错误信息}")
完毕
```
只有一种错误处理机制，错误对象就是一个文本（或含 `.消息` 字段的简单字典）。没有 finally/raise 层级/异常类继承树。抛错用内置函数 `抛出("消息")`。

### D9 标准库极小且全是函数
不超过 30 个内置函数（v4.1 用掉最后一个名额，加入 位置/find），全部小写蛇形命名，中英双名（如 `打印/print`、`读取文件/read_file`、`文本转数/str_to_num`）。不引入模块系统——v1 所有内置函数全局可见；v2 再考虑 `用 "xxx" 引入`。

### D10 报错信息必须说人话
所有错误消息双语（中文优先），带行号和"你可能是想……"的修复建议。例如：`第 3 行：变量 "nmae" 还没有定义。你是不是想写 "name"？`

## 4. 明确砍掉的 Python 特性（文档中要列出并解释理由）

缩进块、类与继承、元组/集合、列表推导式、切片语法（改为 `取(列表, 起, 止)`）、
lambda 多种写法、装饰器、生成器、async/await、类型注解、模块系统（v1）、
多重继承、魔法方法、可变默认参数陷阱、GIL 相关讨论。
