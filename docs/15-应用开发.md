# 16 · 应用开发（v1.7：后端写法 / 写页面 / 桌面应用 / 手机端）

> 读者：初学者 → 实现者。本章把 sahou 从"网站"扩展到"应用"：
> 后端路由与回应的顺手写法、模板文件写页面、桌面应用（浏览器壳）、手机端（局域网 + 添加到主屏幕）。
> 示例：`examples/桌面应用.saho`、`examples/手机应用.saho`；回归：`bash tests/app.sh`。

## 1. 后端写法

### 路径参数路由

`":名"` 一段匹配任意一段路径，捕获进 `请求["参数"]`：

```saho
函数 看文章(请求)
    编号 = 数(请求["参数"]["编号"])
    …
完毕
服务.路由("GET", "/文章/:编号", 看文章)
```

- `/文章/1`、`/文章/abc` 都能命中；字面段要完全相等（`/文章/:编号/评论` 是两段参数混搭）。
- 精确路由优先；参数路由按注册顺序匹配第一个命中的。
- 参数永远是文本，要当数字用时 `数(...)` 转换。

> 为什么不用 `{名}`？语言字符串插值已占用花括号（`"{表达式}"`），路径参数改用 `:名`。

### 快捷回应（网络模块）

| 写法 | 作用 |
|---|---|
| `返回 网络.JSON回应(值)` | 200 + JSON 体（Content-Type 已设好） |
| `返回 网络.JSON回应(值, 404)` | 指定状态码 |
| `返回 网络.网页回应(体)` | 200 + `text/html; charset=utf-8` |
| `返回 网络.重定向("/")` | 302 跳转 |

等价于手写完整响应字典，只是少打几行。

## 2. 写页面

| 写法 | 作用 |
|---|---|
| `网页.渲染文件("模板.html", 数据)` | 从文件读模板再渲染——HTML 放文件里，与代码分离 |
| `网页.页面(标题, 内容)` | 套一个完整 HTML 骨架（utf-8 + 手机 viewport），返回整页文本 |

```saho
写入文件("应用页面/index.html", 网页.渲染文件("模板.html", {"标题": "首页"}))
```

模板文件里的语法与 `网页.渲染` 相同：`[[键]]` 转义取值、`[[[键]]]` 原样、`[[用户.名字]]` 嵌套。
相对路径按脚本所在目录算（与 读取文件 一致）。

## 3. 桌面应用（应用/app 模块）

浏览器壳模型（Electron 的零依赖版）：本地起服务 + 自动打开系统默认浏览器，用户看到的就是一个"应用窗口"。

```saho
应用.窗口("应用页面")          # 目录 → 应用；端口自动分配；Ctrl+C 退出
应用.窗口("应用页面", 8080)    # 指定端口
应用.窗口("应用页面", 0, 真)   # 第三个参数 真 = 不自动开浏览器（测试用）
应用.打开("http://localhost:8080")   # 只开浏览器，不起服务
```

目录相对脚本所在目录算；建议入口文件为 `index.html`。
要交互逻辑就配一份转译 JS（`sahou build`，见 07 文档）一起放进目录。

### 原生窗口（v1.8，仅 Windows 是真窗口）

```saho
应用.原生窗口("应用页面", "我的应用", 宽: 1000, 高: 700)
```

- **Windows**：用系统自带的 WebView2 开一个**真窗口**——没有浏览器地址栏，
  关闭窗口即退出程序。纯 Go 实现、无 CGO，底层依赖 `github.com/jchv/go-webview2`
  （这是本语言**唯一一个第三方依赖**）。
- **非 Windows 平台**：自动退回默认浏览器（等价于 `应用.窗口`）。

## 4. 原生窗口（v1.8，Windows 真窗口）

`应用.原生窗口(目录, 标题, 宽: 1000, 高: 700)`：用系统自带的 **WebView2** 打开一个真正的原生窗口——没有浏览器地址栏、没有标签页，关闭窗口程序即退出：

```saho
应用.原生窗口("应用页面", "我的应用", 900, 600)
```

- Windows 10/11 预装 WebView2 运行时，用户什么都不用装；实现是纯 Go（github.com/jchv/go-webview2，本语言唯一的第三方依赖，无 CGO）。
- 非 Windows 平台自动退回系统默认浏览器（提示后打开）。
- 配合 `sahou 打包`（下一节）可以产出双击即用的单文件 exe。

## 5. 打包成独立程序（v1.8）

```bash
sahou 打包 应用.saho -o 应用.exe
```

生成一个**独立可执行文件**（约 7-8 MB）：脚本被内嵌进 exe，拿到别的 Windows 机器上双击就能跑（无需安装 sahou 或 Go）。约定：

- exe 把**自己所在目录**当作脚本目录：静态资产（`应用页面/`、`stones/`、`*.db` 等）放在 exe 旁边一起分发即可。
- `读取文件/写入文件/数据库.打开` 的相对路径都按 exe 所在目录算。
- 打包这一步需要本机装有 Go 工具链（sahou 会生成临时工程并调用 go build）；运行打包产物不需要。
- 打包出来的程序同样支持 原生窗口/服务.监听/应用.手机 等全部能力。

## 6. 手机端

```saho
应用.手机("应用页面")          # 监听 0.0.0.0:8000，打印局域网网址
```

手机连同一 Wi-Fi，用打印的网址（如 `http://192.168.1.5:8000/`）打开即可使用；
在手机浏览器里选"添加到主屏幕"，即可像原生 App 一样全屏启动（PWA 体验）。
`网页.页面` 生成的骨架已带手机 viewport，页面自动适配窄屏。

## 7. 模块一览（应用/app）

| 成员 | 说明 |
|---|---|
| `应用.窗口(目录, 端口: 0, 静默: 假)` | 桌面应用：本地服务 + 打开浏览器 |
| `应用.原生窗口(目录, 标题, 宽: 1000, 高: 700)` | v1.8：Windows 真 WebView2 窗口；其他平台退回浏览器 |
| `应用.手机(目录, 端口: 8000)` | 手机端：监听局域网并打印网址 |
| `应用.原生窗口(目录, 标题, 宽, 高)` | WebView2 原生窗口（Windows；其他平台退回浏览器） |
| `应用.打开(网址)` | 用系统默认浏览器打开网址 |

仅解释器（本机/服务端）可用；浏览器侧没有"开窗口"的概念。

## 6. 工程化命令（v1.8）

### `sahou 打包 应用.saho -o 应用.exe` —— 独立可执行文件

- 在临时 Go 工程里用 `go:embed` 内嵌脚本，sahou 源码随包一起编译，
  生成**独立可执行文件**（约 7-8 MB）。
- exe 把**脚本目录当作自己所在目录**：静态资产（`应用页面/`、`stones/`、`*.db`）
  放在 exe 旁边即可分发，用户机器上不需要装 sahou。
- **需要本机装有 Go 工具链**（仅打包时用；运行 exe 的用户不需要）。

### `sahou 格式 程序.saho` —— 保守格式化

只重排缩进、去行尾空白、压缩连续空行；**不改写任何记号**，语义不变。

### `sahou 装 https://…/包名.zip` —— 远程 zip 包安装

从 URL 下载 zip 包安装：自动剥掉顶层目录、登记进 `stones.yml`。
