## 1. 术语约定

## 2. 词法规则

### 2.1 源文件与编码

- 源文件必须是 **UTF-8** 编码，允许带 BOM。
- 源文件扩展名：`.saho`。**（【规范补充】）**
- 换行符：`LF` 与 `CRLF` 都接受，且语义相同；解释器不在报错信息中泄露行尾差异。

### 2.2 缩进完全无关（D1）

- 行首的空格与 Tab **一律被忽略**，不参与语法，也不产生任何记号。
- 空格与 Tab **混用不报错**。
- 行尾的空白同样被忽略。
- 空行、只含注释的行不产生语句，也不影响块结构。

因此下面四段代码在语义上**完全等价**，都可以运行：

```
如果 计数 > 3
     print("大")
否则
        print("小")
完毕
```

```
如果 计数 > 3
print("大")
否则
print("小")
    Tab 缩进也不管
完毕
```

> 缩进在 卅 中**只是给人类看的排版**。它的唯一建议用途是让代码好读。

### 2.3 注释

- 注释符：`#`。
- 从 `#` 起到**本行行尾**的全部内容被忽略。
- 文本字面量内部的 `#` **不是**注释（`"井号 # 是字面内容"`）。
- v1 **没有**块注释（`/* */`、`###`），需要多行注释时写多个 `#` 行。

```
# 这一整行都是注释
计数 = 0   # 行尾注释
print("井号 # 在文本里就是井号")   # 只有这行末尾的才是注释
```

### 2.4 记号（token）总表

| 记号类别 | 形式 |
|---|---|
| `标识符` | 见 2.5 |
| `关键字` | 见 2.6，且包含所有中英拼写 |
| `数字` | `10`、`3.5`，见 2.7 |
| `文本` | `"..."` 或 `'...'`，见 2.8 |
| `运算符` | `+ - * / % == != < <= > >= = =>` |
| `分隔符` | `( ) [ ] { } , : .` |
| `换行 NL` | 语句分隔符，见 2.10 |
| `文件结束 EOF` | 输入结束 |

最长匹配原则：`==` 不会被切成两个 `=`；`<=`、`>=`、`!=`、`=>` 同理。

### 2.5 标识符（允许中文）

标识符用于变量名、函数名、参数名、字典的可点取字段名。

- 首字符：Unicode 字母（含汉字）或下划线 `_`。
- 后续字符：Unicode 字母（含汉字）、数字、下划线。
- **不能以数字开头**。
- 英文**区分大小写**（`Name` 与 `name` 是两个不同的名字）。
- 关键字**不能**单独作标识符。
- 表情符号、全角空格、连字符 `-`、点 `.` 都不是合法标识符字符。

合法与非法示例：

```
名字 = "卅"        # 合法：汉字标识符
count_1 = 1          # 合法：下划线 + 数字
_临时 = 空值          # 合法：下划线开头
2号 = 2              # 非法：数字开头
如果 = 1             # 非法：关键字作变量名（建议改成 如果_ 或 result）
my-name = 1          # 非法：连字符被读成减号
```

推荐命名风格：中文名用完整词（`总价`、`乘法表`），英文名用小写蛇形（`total_price`），与内置函数命名一致（D9）。一整套程序中英混用名字是允许的，但同一份程序里最好保持一种语言风格。

### 2.6 关键字：完整双语对照表（D2）

关键字是**同一套语法的两种拼写**，不是两套语言。词法阶段就把中英拼写归为同一个记号，编译器后面的所有阶段完全不知道你写的是中文还是英文。

| 英文 | 中文 | 类别 | 用途 | 示例 |
|---|---|---|---|---|
| `if` | `如果` | 条件 | 条件成立时执行块 | `如果 x > 3` |
| `elif` | `又如` | 条件 | 前一个条件不成立时再判断 | `又如 x == 3` |
| `else` | `否则` | 条件 | 其余情况 | `否则` |
| `while` | `当` | 循环 | 条件为真时反复执行块 | `当 计数 < 3` |
| `for` | `遍历` | 循环 | 逐个遍历列表（或文本、字典） | `for i 于 从a到b(1, 10)` |
| `in` | `于` | 循环 | `for` 与序列之间的连接词 | `遍历 名字 于 名单` |
| `end` | `完毕` | 块 | 收尾任意块（D1） | `完毕` |
| `fn` | `函数` | 函数 | 定义具名函数，或写匿名函数 | `函数 加(a, b)` / `函数(x) => x + 1` |
| `return` | `返回` | 函数 | 从函数返回值；顶层返回即结束程序 | `返回 a + b` |
| `let` | `设` | 变量 | **可选**的赋值前缀，写不写都一样 | `设 计数 = 0` |
| `true` | `真` | 字面量 | 布尔真 | `设 通过 = 真` |
| `false` | `假` | 字面量 | 布尔假 | `设 通过 = 假` |
| `null` | `空值` | 字面量 | 空值（D4 的"外加一个空值"） | `设 结果 = 空值` |
| `and` | `并且` | 逻辑 | 逻辑与，短路求值 | `x > 0 并且 x < 10` |
| `or` | `或者` | 逻辑 | 逻辑或，短路求值 | `名称 == "猫" 或者 名称 == "狗"` |
| `not` | `非` | 逻辑 | 逻辑非（一元） | `非 完成` |
| `try` | `尝试` | 错误 | 尝试块开始（D8） | `尝试` |
| `catch` | `接住` | 错误 | 接住错误并把错误信息绑定到名字 | `接住 错误信息` |
| `use` | `用` | 模块（v2） | 引入一个模块 | `用 "网络" 引入` |
| `import` | `引入` | 模块（v2） | 引入语句的收尾词，**可省略** | `用 "网络" 引入` / `用 "网络"` |
| `cell` | `格子` | 响应式（v4） | 定义响应式格子（数据流，见 13 文档） | `格子 总价 = 单价 * 数量` |
| `break` | `跳出` | 循环（v4.1） | 结束最近一层循环 | `跳出` |
| `continue` | `继续` | 循环（v4.1） | 跳过本轮循环剩余部分 | `继续` |

**关于 `尝试/接住`**：简报 D8 的示例只给出了中文拼写 `尝试` / `接住`，未列出英文拼写。
本规范依据 D2"每条语句提供等价的中文关键字"的对称性，把英文写作 `try` / `catch`。**（【规范补充】）**

**关于缺失的关键字（历史说明，v4.1 已修订）**：简报的关键字表最初**没有** `break`/`continue`/`跳出`/`继续`，本规范也据此未提供。
后来 v4.1 按用户需求把 `跳出/break`、`继续/continue` **正式纳入**（上表已列，总数 23 个）；
`class`、`raise`、`finally` 仍然不提供（用 字典+函数 与 `抛出`/`尝试/接住` 代替，见第 10 节）。

### 2.7 数字字面量（D3）

只有一种**数**，所以字面量也只有两种写法：

| 形式 | 写法 | 说明 |
|---|---|---|
| 整数写法 | `0`、`10`、`42`、`2024` | 内部用精确整数表示 |
| 小数写法 | `3.5`、`0.5`、`10.0` | 小数点前后**都必须有数字** |

- `.5` 与 `5.` 都是**错误**的（新手最常见的输入法/手滑问题），报错会建议写成 `0.5`、`5.0`。
- **不支持**科学计数法（`1e3`）、十六进制（`0xFF`）、八进制、二进制、千位分隔符（`1_000`、`1,000`）。
  需要 `1000` 就写 `1000`；需要二进制请自己写辅助函数。
- 负号是**一元运算符**，不是字面量的一部分：`-3` 由 `-` 与 `3` 组合而成。
- `10` 与 `10.0` **是同一个值**：`10 == 10.0` 为 `真`（D3）。
- 不支持 `+` 作为数字前缀（`+3` 报错，建议写 `3` 或 `0 + 3`）。

### 2.8 文本字面量与转义（D6）

文本字面量用半角双引号 `"` 或半角单引号 `'` 包围，两者完全等价：

```
问候 = "你好"
同一条 = '你好'
```

**转义序列**（反斜杠 `\`）：

| 写法 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 一个反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\{` | 字面左花括号（不开始插值） |
| `\}` | 字面右花括号 |

- 文本字面量**不能跨行**，要换行请写 `\n`。**（【规范补充】）**
- 花括号只有一种转义方式：`\{` 与 `\}`。写 `{{` 会报错并提示改用 `\{`。**（【规范补充】）**
- 未知转义（如 `\q`）报错，并列出所有合法转义，而不是默默当成 `q`。
- 插值 `{表达式}` 见 5.5 节。

### 2.9 标点必须半角（D10 的落实点）

中文输入法很容易打出全角标点，这是中文学习者最高频的"环境错误"。规范强制：

- 语法标点**必须**用半角：`( ) [ ] { } , : . " ' + - * / % = < >`。
- 全角标点（`（ ） 【 】 ， ： 。 "" ''` 等）在语法位置出现时**必须报出专门的错误**，并明确告诉你"你打的是全角，应该打半角"，而不是一句笼统的"语法错误"。
- 中文文本的**内容**当然可以用全角标点：`抛出("成绩必须是数字，收到: 95")` 里的中文顿号、逗号、句号都在引号内，完全合法。

```
如果 计数 > 3，        # 错误：行尾是中文逗号"，"
    print("大")
完毕
```

```
第 1 行：这里应该是半角逗号 ","，你打成了中文逗号 "，"。
line 1: expected "," but found "，".
  提示：把输入法切换到英文标点，或者删掉这个逗号（这里的逗号本来就不需要）。
```

### 2.10 换行与语句分隔

- 语句之间用**换行**分隔；分号 `;`（或全角 `；`）也可以作为语句结束符，效果与换行完全相同（v2 增补），因此 `a = 1; b = 2` 是合法的一行两条语句。
- 分号**不能**用来把一个语句拆成两半，也**不需要**在行尾补写——它只是换行的另一种写法。
- 圆括号 `( )`、方括号 `[ ]`、花括号 `{ }` **内部**的换行被忽略，因此长调用、长列表、长字典可以放心折行：

```
小猫 = {
    "名字": "咪咪",
    "饥饿": 0,
}

print(
    喂食(小猫),
    结尾: "\n"
)
```

- 块结构靠 `end`/`完毕` 收尾，**不靠**换行或缩进，所以下面这种"收尾词单独成行"只是排版选择：

```
如果 计数 > 3
    print("大")
完毕
```

## 3. 运算符

### 3.1 运算符总表

| 运算符 | 中英说明 | 左操作数 | 右操作数 | 结果 | 示例 |
|---|---|---|---|---|---|
| `-`（一元） | 取负 | — | 数 | 数 | `-3`、`-半径` |
| `非` / `not` | 逻辑非 | — | 任意 | 布尔 | `非 完成` |
| `*` | 乘 / 文本重复 / 列表重复 | 数|文本|列表 | 数（数值乘法）或 数（重复次数） | `3 * 4`、`"-" * 10`、`[0] * 3` |
| `/` | 除（**永远是真除法**，D3） | 数 | 数 | 数 | `10 / 3` |
| `%` | 取余 | 数 | 数 | 数 | `10 % 3` 得 `1` |
| `+` | 加 / 文本拼接 / 列表拼接 | 数+数、文本+文本、列表+列表 | 同左 | 数/文本/列表 | `1 + 2`、`"a" + "b"`、`[1] + [2]` |
| `-`（二元） | 减 | 数 | 数 | 数 | `5 - 2` |
| `==` | 相等比较 | 任意 | 任意 | 布尔 | `10 == 10.0` 得 `真` |
| `!=` | 不相等比较 | 任意 | 任意 | 布尔 | `1 != "1"` 得 `真` |
| `<` `<=` `>` `>=` | 大小比较 | 数+数 或 文本+文本 | 同左 | 布尔 | `i <= 9` |
| `并且` / `and` | 逻辑与（短路） | 任意 | 任意 | 布尔 | `x > 0 并且 x < 10` |
| `或者` / `or` | 逻辑或（短路） | 任意 | 任意 | 布尔 | `a == 1 或者 a == 2` |
| `=` | 赋值（**语句**，不是表达式） | 左值 | 任意 | 无 | `计数 = 计数 + 1` |
| `=>` | 匿名函数 | — | 表达式 | 函数 | `函数(x) => x * 2` |
| `( )` | 函数调用 / 分组 | — | — | 取决于被调用函数 | `print("hi")`、`(1 + 2) * 3` |
| `[ ]` | 索引取值 / 列表字面量 | — | — | 元素 / 列表 | `名单[0]`、`[1, 2]` |
| `{ }` | 字典字面量 | — | — | 字典 | `{ "名字": "咪咪" }` |
| `.` | 成员访问 | 字典/列表 | 标识符 | 字段值 / 成员函数 | `动物.名字`、`列表.去重()` |
| `:` | 字典键值分隔 / 命名实参 | — | — | — | `{"a": 1}`、`结尾: "  "` |
| `,` | 分隔多个元素或实参 | — | — | — | `print(x, 结尾: "!")` |
| `#` | 注释 | — | — | — | `# 说明` |

### 3.2 优先级与结合性表

从**最高**到**最低**（同级从左到右结合，除注明外）：

| 级别 | 运算符 | 结合性 | 说明 |
|---|---|---|---|
| 1 | `()` `[]` `.` | 左 | 调用、索引、成员访问（后缀，最高） |
| 2 | `-`（一元） | 右 | 取负 |
| 3 | `*` `/` `%` | 左 | 乘、除、取余 |
| 4 | `+` `-` | 左 | 加、减、拼接 |
| 5 | `==` `!=` `<` `<=` `>` `>=` | **不可连写** | 比较，见下 |
| 6 | `非` / `not` | 右 | 逻辑非 |
| 7 | `并且` / `and` | 左 | 逻辑与（短路） |
| 8 | `或者` / `or` | 左 | 逻辑或（短路） |
| 9 | `函数(参数) => 表达式` | 右 | 匿名函数体延伸到最右（最低） |
| — | `=` | 语句级 | 不是表达式，因此**不能**写 `a = b = c` |

**比较运算符不可连写**：`a < b < c` 是**错误**，因为它的含义对新手是陷阱（Python 里它是 `a < b 并且 b < c`，很多语言里是 `(a < b) < c`）。
报错会直接给出改写建议。**（【规范补充】）**

```
如果 0 < 分数 < 100        # 错误
如果 0 < 分数 并且 分数 < 100   # 正确写法
```

### 3.3 语义细节与类型规则

**算术**

- `+ - * %` 只接受**数**（`+` 与 `*` 另有文本/列表重载，见下）；其他类型报错并给转换建议。
- `/` 是**真除法**，永远返回数：`10 / 3` 得 `3.3333...`；没有 `//`，也没有整除运算符（D3、D7）。
- 除以 `0` 报错：`第 N 行：不能除以 0。`（可被 `接住`）。
- `%`（取余）对 `0` 取余同样报错。余数的符号跟随被除数（与 Python 一致：`-7 % 3` 得 `2`）。
- 数的内部表示见 5.2 节（自动整/浮、精度与打印规则）。

**文本与列表的 `+` / `*`**

- `文本 + 文本`：拼接。`"小" + "石"` 得 `"卅"`。
- `文本 * 数`、`数 * 文本`：重复。`"-" * 10` 得 `"----------"`；重复次数必须是非负整数，`负数` 报错建议写 `0`，小数报错建议 `四舍五入`。
- `列表 + 列表`：拼接为新列表。`[1, 2] + [3]` 得 `[1, 2, 3]`。
- `列表 * 数`、`数 * 列表`：重复。`[0] * 3` 得 `[0, 0, 0]`。
- `文本 + 数`、`列表 + 文本` 等**混合**运算报错，并给出 `文本(...)` 的修复建议（D10）：

```
第 12 行：不能把 文本 和 数 相加。你可能是想把数字转换成文本，试试 文本(数量)？
line 12: cannot add 文本 and 数. Maybe convert the number to text with 文本(数量)?
```

**比较**

- 数与数：按**数学值**比较，因此 `10 == 10.0` 为 `真`、`10 < 10.5` 为 `真`。
- 文本与文本：逐字符按 Unicode 码位比较，区分大小写（`"A" != "a"`）。要忽略大小写请先 `转小写(...)`。
- 布尔与布尔：`假 < 真`。
- 列表与列表、字典与字典：**深度相等**（逐元素/逐键值递归比较），见 5.10 节。
- 空值与空值：`==` 得 `真`。
- **跨类型比较**：`==` 与 `!=` 返回 `假` / `真`，**不报错**（`1 == "1"` 得 `假`，`真 == 1` 得 `假`）；
  但 `<` `<=` `>` `>=` 跨类型**报错**，因为"文本和数谁大"没有合理答案。**（【规范补充】）**

**逻辑**

- `并且` / `或者` **短路求值**：`并且` 左边为假就不再算右边；`或者` 左边为真就不再算右边。
- 操作数按 5.4 节的真值规则解释；结果**永远是布尔值** `真`/`假`，**不返回**参与运算的操作数本身。**（【规范补充】）**
  因此 Python 里 `x = a 或者 默认值` 这种写法在 卅 中无效，应写成显式的条件语句。
- `非` 只接受一个操作数，结果永远是布尔。

**赋值**

- `=` 是**语句**，右侧先求值，再写入左侧。
- 左侧（左值）只允许三种形式：标识符 `x`、索引 `d["键"]` / `xs[i]`、成员 `d.键`。
- `a = b = c`、`如果 (x = 1)` 之类的写法报错，并提示"赋值不能写在表达式里，请分两行写"。
- `设`/`let` 只能前缀在**标识符**赋值上：`设 x = 1` 合法，`设 d["k"] = 1` 报错并提示去掉 `设`。**（【规范补充】）**
- 给未定义的变量名赋值会**创建**该变量（无需声明）；读取未定义的变量名报错并给拼写建议。

## 4. 语法（EBNF）

### 4.1 记号约定

- `::=` 定义，`|` 选择，`{ }` 重复零次或多次，`[ ]` 可选。
- `"..."` 是终结符字面量；中英拼写并列出现即表示二者等价。
- `换行 NL`：词法阶段的语句分隔记号。为可读性，下文 `{ 语句 }` 之间隐含 `NL`；`( ) [ ] { }` 内部的 `NL` 被丢弃（见 2.10）。

### 4.2 完整文法

```ebnf
程序        ::= { 语句 } EOF ;

语句        ::= 赋值语句
              | 表达式语句
              | 如果语句
              | 当语句
              | 遍历语句
              | 函数定义语句
              | 返回语句
              | 尝试语句 ;

(* ---------- 赋值 ---------- *)
赋值语句    ::= [ "let" | "设" ] 左值 "=" 表达式 ;
左值        ::= 标识符
              | 左值 "[" 表达式 "]"
              | 左值 "." 标识符 ;

(* ---------- 表达式语句 ---------- *)
表达式语句  ::= 表达式 ;

(* ---------- 条件 ---------- *)
如果语句    ::= ( "if" | "如果" ) 表达式 换行 { 语句 }
                { ( "elif" | "又如" ) 表达式 换行 { 语句 } }
                [ ( "else" | "否则" ) 换行 { 语句 } ]
                ( "end" | "完毕" ) ;

(* ---------- 循环 ---------- *)
当语句      ::= ( "while" | "当" ) 表达式 换行 { 语句 }
                ( "end" | "完毕" ) ;

遍历语句    ::= ( "for" | "遍历" ) 标识符 ( "in" | "于" ) 表达式 换行 { 语句 }
                ( "end" | "完毕" ) ;

(* ---------- 函数 ---------- *)
函数定义语句 ::= ( "fn" | "函数" ) 标识符 "(" [ 参数表 ] ")" 换行 { 语句 }
                 ( "end" | "完毕" ) ;
参数表      ::= 标识符 { "," 标识符 } ;
返回语句    ::= ( "return" | "返回" ) [ 表达式 ] ;

(* ---------- 错误处理 ---------- *)
尝试语句    ::= ( "try" | "尝试" ) 换行 { 语句 }
                ( "catch" | "接住" ) 标识符 换行 { 语句 }
                ( "end" | "完毕" ) ;

(* ---------- 表达式 ---------- *)
表达式      ::= 匿名函数 | 或者表达式 ;
匿名函数    ::= ( "fn" | "函数" ) "(" [ 参数表 ] ")" "=>" 表达式 ;

或者表达式  ::= 并且表达式 { ( "or" | "或者" ) 并且表达式 } ;
并且表达式  ::= 非表达式 { ( "and" | "并且" ) 非表达式 } ;
非表达式    ::= ( "not" | "非" ) 非表达式 | 比较表达式 ;

比较表达式  ::= 加减表达式 [ 比较运算符 加减表达式 ] ;
比较运算符  ::= "==" | "!=" | "<" | "<=" | ">" | ">=" ;

加减表达式  ::= 乘除表达式 { ( "+" | "-" ) 乘除表达式 } ;
乘除表达式  ::= 一元表达式 { ( "*" | "/" | "%" ) 一元表达式 } ;
一元表达式  ::= "-" 一元表达式 | 后缀表达式 ;

后缀表达式  ::= 基本表达式 { 后缀 } ;
后缀        ::= "(" [ 实参表 ] ")"
              | "[" 表达式 "]"
              | "." 标识符 ;
实参表      ::= 实参 { "," 实参 } ;
实参        ::= 表达式 | 标识符 ":" 表达式 ;   (* 后者是命名实参，如 结尾: "  " *)

基本表达式  ::= 数字
              | 文本
              | "true" | "真"
              | "false" | "假"
              | "null" | "空值"
              | 标识符
              | "(" 表达式 ")"
              | 列表字面量
              | 字典字面量 ;

列表字面量  ::= "[" [ 表达式 { "," 表达式 } ] "]" ;
字典字面量  ::= "{" [ 字典项 { "," 字典项 } ] "}" ;
字典项      ::= 表达式 ":" 表达式 ;
```

### 4.3 文法注记

1. **块的收尾两种等价风格（v2 增补）**：`end`/`完毕` 收尾（D1 原生），或 Java 式花括号 `{ }` 收尾——块头之后直接跟 `{`（同行或下一行均可），闭花括号后不需要 `完毕`。花括号风格允许空块；两种风格**完全等价**，同一块内不要混用（如 如果 用了花括号，其 否则 也必须用花括号）。花括号内部语句仍以换行分隔。
2. **块体不可为空**：`如果 x` 后面直接跟 `完毕` 报错，提示"这个块里什么也没有，至少写一条语句，或者把它删掉"。
3. **嵌套就是字面嵌套**：内层块的 `完毕` 只关闭内层，三层嵌套就要三个 `完毕`（见 8.1 的乘法表示例）。
4. **缺收尾词**是最常见的语法错误，报错必须指出**哪个块在第几行开始**，而不是只说"意外的文件结束"（见 7.2 示例 3）。
5. **多余的收尾词**同样报错，并指出它可能是想关闭哪一行开始的块。
6. **命名实参必须写在位置实参之后**；同一个参数不能既按位置又按名字给两次。
7. **匿名函数体延伸到最右**（优先级最低），所以 `函数(x) => x + 1` 的函数体是 `x + 1`；需要限制范围就加括号：`函数(x) => (x + 1) * 2`。
8. **用户函数没有默认参数值**（D5、01 文档第 5 节"可变默认参数陷阱"）：参数表只写名字。可选性由内置函数的命名参数提供。

## 5. 语义规则

### 5.1 类型系统：五种类型 + 一个空值（D4）

| 类型 | 中文名 | 英文名 | 字面量 | 说明 | `文本(值)` 的输出 |
|---|---|---|---|---|---|
| 数 | 数 | number | `10`、`3.5` | 唯一的数值类型，内部自动整/浮 | `10`、`3.5` |
| 文本 | 文本 | string | `"你好"`、`'hi'` | Unicode 字符序列，不可变 | `你好`（不带引号） |
| 列表 | 列表 | list | `[1, 2, 3]`、`[]` | 有序、可变、可重复、可混合类型 | `[1, 2, 3]` |
| 字典 | 字典 | dict | `{"名字": "咪咪"}`、`{}` | 键值对，键为文本或数，可变 | `{"名字": "咪咪"}` |
| 布尔 | 布尔 | bool | `真`/`false`、`假`/`true` | 只有两个值 | `真` / `假` |
| 空值 | 空值 | null | `空值` / `null` | "没有值"的唯一表示，**不是第六种类型** | `空值` |

- **没有**元组、集合、字节、复数、类、日期类型、函数类型（D4）。
  需要"集合"语义时用列表 + `列表.去重()`（简报 D4 原文写法）。
- 需要"结构化数据"时用字典 + 函数组合（见 8.2 示例）。
- 函数是**值**（一等公民，D5），可以赋给变量、当实参传、当返回值返回；`类型(函数)` 返回 `"function"`（见 6.2 的类型取值）。
  函数值**不能**参与 `+`、比较大小等运算。
- 列表与字典的元素可以是任意类型，包括 `空值`、函数，以及它们自己（自引用）。

### 5.2 单一"数"类型的自动整/浮行为（D3）

**给用户看的规则（三条，必须背下来也只有三条）**

1. 只有一种数，写 `10` 和写 `10.0` 是同一个值，`10 == 10.0` 为 `真`。
2. `/` 永远是**真除法**：`10 / 3` 得 `3.3333...`，不做整除特例。
3. 打印时，能整除或本来就是整数结果显示成整数：`print(4 / 2)` 输出 `2`；`print(10 / 3)` 输出 `3.3333...`。

**实现层面的规则**

- 内部用两种表示承载这**一个**类型：**精确整数**与**有限精度小数**。这是实现细节，语言层面**不暴露**，也不允许用户指定。
- **整数精确性必须保证**：计数、索引、比较永远不出错。`列表[2]` 的 `2`、`for i 于 从a到b(1, 10)` 的 `i` 都不会因为浮点误差变成 `2.0000000000000004`。
- 当一个运算的两个操作数都是整数且运算本身不产生小数（`+ - *`、以及能整除的 `/`、取余 `%`）时，结果保持精确整数表示。
- 只要出现小数或除不尽，就转入有限精度小数表示。**（【规范补充】）**
  为彻底消除 D3 点名要消除的 `0.1 + 0.2 != 0.3` 类困惑，规范规定小数使用**十进制、15 位有效数字**的表示（实现建议：Python `decimal`，`prec = 15`）。于是：
  - `0.1 + 0.2 == 0.3` 为 `真`；
  - `10 / 3` 打印为 `3.33333333333333`（15 位有效数字，去掉尾部多余的 `0`）；
  - `平方根(2)` 等运算结果同样按 15 位有效数字舍入。
  本文档其余位置仍按简报的写法使用 `3.3333...` 表示"一个很长的十进制小数"。
- 打印一个数时采用**最短且能唯一还原该值**的十进制写法，去掉无意义的尾部零与小数点（所以永远看不到 `10.0`，只见 `10`）。
- 数没有 `NaN`、没有 `Infinity` 字面量：`0 / 0` 与 `1 / 0` 都是**可被接住的错误**，不是特殊值。

```
print(10)          # 10
print(3.5)         # 3.5
print(10 == 10.0)  # 真
print(10 / 3)      # 3.3333...
print(4 / 2)       # 2
print(10 % 3)      # 1
```

### 5.3 作用域：只有函数作用域

**规则（v1 的核心简化）**

1. 作用域只有两种：**每个函数一个作用域**，以及**顶层（主程序）作用域**。
2. `如果`、`又如`、`否则`、`当`、`遍历`、`尝试`、`接住` 的块**不创建新作用域**。块内赋值的变量在块结束后**依然存在**。
3. 函数内第一次给某名字赋值，就在**当前函数作用域**创建变量（局部变量）。
4. 函数内读取某名字时，先找当前函数作用域，再找定义处的外层作用域（**词法作用域**）。找不到就报错并给拼写建议。
5. 函数内给一个"外层已存在的名字"赋值，**不会**修改外层变量，而是在当前函数作用域创建一个同名新变量（**遮蔽**，shadowing）。
   v1 **没有** `global`/`nonlocal` 之类的关键字，也不打算有。
6. 参数是函数作用域的局部变量；函数调用结束后局部变量消失。

```
计数 = 0

函数 尝试累加()
    计数 = 计数 + 99     # 这是新建一个局部变量，不是改外面的
    返回 计数
完毕

print(尝试累加())   # 99
print(计数)        # 0（外层没变）
```

**可变对象的引用语义（很重要，也是 8.2 示例能工作的原因）**

- 变量名保存的是**值的引用**。数、文本、布尔、空值是**不可变**的：对它们"修改"只能是重新赋值。
- 列表与字典是**可变**的。通过 `动物["饥饿"] = ...`、`列表.添加(...)` 修改的是**共享的那个对象本身**，所以调用者看得见：

```
小猫 = { "名字": "咪咪", "饥饿": 0 }

函数 喂食(动物)
    动物["饥饿"] = 动物["饥饿"] - 10   # 改的是同一个字典对象
    返回 "{动物["名字"]} 吃饱啦，饥饿度 {动物["饥饿"]}"
完毕

print(喂食(小猫))
```

- 但如果函数里对参数**整体重新赋值**（`动物 = {...}`），那只是换掉了局部变量指向的对象，调用者的变量不受影响。
- 列表、字典作为实参传入时**不复制**（v1 没有深拷贝/浅拷贝函数）；要副本请写 `列表(原列表)` 做浅拷贝。

### 5.4 真值规则

条件位置包括：`如果`/`又如`/`当` 的条件、`并且`/`或者`/`非` 的操作数。

**只有 6 个值是"假"**，其余一切都是"真"：

| 假值 | 说明 |
|---|---|
| `假` / `false` | 布尔假 |
| `空值` / `null` | 没有值 |
| `0` | 数值零（含 `0.0`，因为只有一种数） |
| `""` | 空文本 |
| `[]` | 空列表 |
| `{}` | 空字典 |

由此可以推出几条必须记住的推论：

- `"0"`、`"假"`、`" "`（一个空格）都是**真**：非空文本就是真。
- `-1`、`0.5` 是**真**。
- `[0]`、`{"a": 0}` 是**真**：非空容器就是真，**不看内容**。（这是对 Python 的简化：Python 里 `[0]` 也是真，但"容器只看空不空"被写死成一条更容易记的规则。）
- 真值判断**不需要**写 `== 真`：写 `如果 完成`，不要写 `如果 完成 == 真`；后者虽然能运行，但报错文档中不推荐。
- 需要把任意值转成布尔时，写 `非 非 值`（连续两次逻辑非）。v1 没有独立的"转布尔"内置函数，以维持 30 个上限（D9）。**（【规范补充】）**

```
如果 []           # 假，不执行
     print("空列表为假")
完毕

如果 "0"          # 真，执行
     print("非空文本为真")
完毕
```

### 5.5 文本插值（D6）

- 文本字面量中，`{` 与 `}` 之间可以放**任意表达式**，求值后用 `文本(...)` 的规则转成文本插入。
- 插值在**每次执行到这行文本**时求值（不是定义时、也不是编译时），所以循环里每轮的值不同。
- 插值**只有一层**：插入结果里如果含 `{...}`，**不会**再次插值。
- `\{`、`\}` 表示字面花括号；插值表达式的括号必须配对，否则报错并指出第几个字符不匹配。
- 花括号里可以是任意表达式，包括索引、成员、函数调用、比较、逻辑运算和匿名函数调用：

```
设 名字 = "卅"
设 单价 = 3.5
设 数量 = 4

print("你好, {名字}!")                    # 你好, 卅!
print("总价是 {单价 * 数量} 元")           # 总价是 14 元
print("多买一件就是 {单价 * (数量 + 1)} 元")
print("够不够便宜？{单价 < 5}")            # 够不够便宜？真
print("列表长度 {长度([1, 2, 3])}")        # 列表长度 3
print("花括号写成 \{这样\}")               # 花括号写成 {这样}
```

- **插值中可以再写文本字面量**（这是 D6 与嵌套引号的必要规则）：进入 `{` 之后词法分析器切回"表达式模式"，所以下面的写法合法，且与简报第 3 节示例逐字一致：

```
返回 "{动物["名字"]} 吃饱啦，饥饿度 {动物["饥饿"]}"
```

- 插值中表达式的类型不限，`文本(...)` 的转换规则见 5.1 表最后一列；`文本(列表)`、`文本(字典)` 用 `[1, 2]`、`{"名字": "咪咪"}` 这种**可直接粘贴回代码**的形式。
- 自引用的容器转换时输出 `<循环引用>`，不会死循环。**（【规范补充】）**

### 5.6 列表与字典字面量

```
空列表 = []
混合 = [1, "二", 真, 空值, [3.5]]
空字典 = {}
小猫 = { "名字": "咪咪", "饥饿": 0 }
```

- 元素之间用**半角逗号**分隔；允许尾随逗号（`[1, 2,]` 合法），折行也合法（2.10）。
- 列表字面量每次执行都会新建一个列表对象，**不能**用它做"共享默认值"之类的花招。
- 字典键必须是**文本**或**数**（v1 只允许这两种）；用列表/字典作键报错并提示"键必须是文本或数"。
  文本键区分大小写：`"名字"` 与 `"姓名"` 是两个键。
- 同一个字典字面量里出现重复键：**后写的覆盖先写的**，并在运行时给出**警告级提示**（不中断程序）。**（【规范补充】）**

### 5.7 成员访问与索引

**索引 `值[键]`**

| 被索引的值 | 键的含义 | 越界/缺键行为 |
|---|---|---|
| 列表 | 位置，**从 0 开始** | 报错，给出合法范围 `0..长度-1` |
| 文本 | 位置，从 0 开始，返回**一个字符的文本** | 报错，给出合法范围 |
| 字典 | 键 | 报错，给出候选键建议 |

- **不允许负索引**：`名单[-1]` 报错并提示改写 `名单[长度(名单) - 1]`。**（【规范补充】）**
- 不允许切片语法（D7、01 文档第 5 节）：一律用 `取(列表, 起, 止)`。
- 给列表越界位置赋值**不会**自动扩容：`名单[5] = "新"` 报错并提示用 `名单.添加("新")`。
- 给字典的新键赋值**可以**创建新键：`动物["年龄"] = 1` 合法。
- 给文本的某一位赋值报错：文本不可变，请用 `替换`、`分割`、`连接` 组合出新文本。

```
名单 = ["小明", "小红"]
print(名单[0])        # 小明
print(名单[长度(名单) - 1])   # 小红
print(取(名单, 0, 1))  # ["小明"]

小猫 = { "名字": "咪咪", "饥饿": 0 }
print(小猫["名字"])    # 咪咪
print(小猫.名字)       # 咪咪（点号是索引的语法糖）
小猫["年龄"] = 1       # 新键，合法
```

**成员访问 `值.名字`**

- **字典**：`动物.名字` **等价于** `动物["名字"]`；键不存在时的报错与 `动物["名字"]` 相同，并**列出该字典现有的键**作为候选建议。
- **列表**：`列表.成员(...)` 是**成员函数**，见 6.4 节（如简报 D4 写法的 `列表.去重()`）。
- **文本**：`文本.成员(...)` 是成员函数，见 6.4 节。
- 对**数、布尔、空值、函数**使用 `.` 报错：`第 4 行：数 没有成员。` 并提示"数只有一种，没有可取的字段"。
- 点号后的名字必须是**标识符**（`动物.名字` 可以，`动物."名字"` 非法，报错建议改成 `动物["名字"]`）。

### 5.8 函数与调用

- 定义（D5，唯一的一种写法）：

```
函数 加(a, b)
    返回 a + b
完毕
```

- 匿名函数（唯一的匿名写法）：`函数(参数) => 表达式`，可以立即调用，也可以赋给变量后传参：

```
双倍 = 函数(x) => x * 2
print(双倍(21))                       # 42
print(取(从a到b(1, 6), 0, 3))          # [1, 2, 3]
函数(x) => print("马上执行 {x}")        # 定义但不保存（合法，但没人能再调用它）
```

- 调用：位置实参按定义顺序绑定；命名实参用 `名字: 值`，必须写在位置实参之后，且名字必须与参数名完全一致。
- 参数个数不符、命名实参名字不存在、同名实参给两次，都报错，并给"你是不是想写……"的候选参数名建议。
- 没有默认参数、没有 `*args`/`**kwargs`、没有装饰器、没有方法重载（D5）。
- 递归合法（函数体内可以调用自己），但 v1 没有尾调用优化；递归过深会报"调用太深"的可接住错误。**（【规范补充】）**
- `返回` 不带表达式时返回 `空值`。函数体执行到最后一条语句也没遇到 `返回` 时，返回 `空值`。
- 顶层（函数外）写 `返回` 表示**结束整个程序**，可带一个值作为退出码含义由实现决定（v1 建议：带值仅作打印提示）。**（【规范补充】，同时也是"不引入 `退出/exit` 内置函数"的替代方案）**
- 函数体里可以读取定义处外层作用域里已存在的变量（词法作用域），但不能给它们赋值（5.3 第 5 条）。

### 5.9 语句语义

**如果 / 又如 / 否则**

- 条件按 5.4 真值规则判断；`又如` 分支可以出现多次，顺序判断，第一个成立的分支执行后其余全部跳过。
- `否则` 必须写在最后，最多一个。`又如` 写在 `否则` 之后报错。

```
如果 分数 >= 90
    print("优秀")
又如 分数 >= 60
    print("及格")
否则
    print("要加油")
完毕
```

**当（while）**

- 条件为真时反复执行块体，直到条件为假。
- 条件必须在块体内被改变，否则是死循环；本文写作时（v1）没有 `break`（v4.1 已加入 `跳出`），也没有超时保护。**（【规范补充】）**

```
计数 = 0
当 计数 < 3
    计数 = 计数 + 1
完毕
```

**遍历（for）**

- `遍历 名字 于 序列` 逐个取值：列表给出元素，文本按**字符**给出（每个元素是一个单字符文本），字典给出**键**。
- 每轮把当前值绑定到循环变量；循环结束后循环变量**仍然存在**，值是最后一轮的值（因为块不创建作用域，5.3）。
- 循环中**不修改**被遍历的列表（`列表.添加` 等），v1 对此**不保证**行为，文档不推荐这么写。**（【规范补充】）**
- 遍历 `空值`、数、布尔报错，并给"它不是一个可遍历的值，可用的有 列表/文本/字典"的建议。

```
for i 于 从a到b(1, 4)
    print(i)          # 1 2 3
完毕
print(i)              # 3（循环变量在循环后依然存在）
```

**尝试 / 接住（D8）**

```
尝试
    危险操作()
接住 错误信息
    print("出错了: {错误信息}")
完毕
```

- `尝试` 块中任何一步出错（包括调用链深处出错、`抛出` 主动抛错），立即跳到 `接住` 块。
- `接住 错误信息` 把**错误信息**绑定为一个**文本**（错误对象就是一句话，D8），可以打印、插值、再 `抛出`。
- **没有**错误类型、没有 `finally`、没有异常类继承树、没有 `raise` 语句（只有内置函数 `抛出`）。
- 一个 `尝试` 只能有**一个** `接住`；想区分不同错误就检查错误信息文本（如 `如果 包含(错误信息, "文件")`）。
- 没有被接住的错误会**终止程序**，并打印：出错的第几行、中文消息、英文消息、建议，以及**调用链**（在哪一行、在哪个函数里调用导致的）。
- `接住` 块自己出错时，该错误向外传播到外层 `尝试`，外层也没有则终止程序。
- `返回` 写在 `尝试` 块里会正常返回，不会执行 `接住`。

### 5.10 相等、比较与打印

- **深度相等**：列表与列表、字典与字典逐元素/逐键值递归比较（键的顺序不影响字典相等：`{"a":1,"b":2} == {"b":2,"a":1}` 为 `真`）。
- 自引用容器的相等比较在检测到循环时**报错**（可接住），避免无限递归。**（【规范补充】）**
- 打印/转换规则：数用最短十进制、文本原样（**不带引号**）、列表 `[1, "二"]`、字典 `{"a": 1}`、布尔 `真`/`假`、空值 `空值`、函数 `<函数 加>` / `<匿名函数>`。
- 列表/字典嵌套时按同样规则递归打印。
- 没有"重载打印"的魔法方法（D4、01 文档第 5 节），要自定义输出格式就写函数返回文本。

## 6. 标准库（D9：不超过 30 个内置函数）

### 6.1 命名与调用约定

- 每个内置函数有**中文名与英文名**，指向**同一个函数**，两者完全等价。
- 中文名是"能读出来的一句人话"（`从a到b`、`文本`、`四舍五入`），英文名是**小写蛇形**（`range_to`、`str`、`round`）——与 Python 迁移路径一致（D9、01 文档对照表）。
- 全部内置函数**全局可见，不需要引入**（v1 无模块系统）。
- 内置函数**不能被重新定义**：`函数 长度(x)` 报错并提示"长度是内置函数，请换个名字，如 长度2"。
- 可选参数通过**命名实参**提供，例如 `print("x", 结尾: "  ")`；参数名同样中英双名（`结尾`/`end`、`分隔`/`sep`、`步长`/`step`、`小数位`/`digits`）。
- 内置函数名字也是**保留名**，共 30 个，不进入关键字表。
- 调用内置函数出错时使用与用户代码同样的错误格式（第 7 节），**不泄露**实现语言（Python）的异常文本。

### 6.3 重点函数详解

**`打印(值, 结尾: "\n")` / `print`**——最常用的函数，简报第 3 节示例里用 `结尾` 抵消换行：

```
print("你好")                     # 输出 你好 并换行
print("你好", 结尾: "")           # 输出 你好 不换行
print("{i}×{j}={i * j}", 结尾: "  ")   # 用两个空格代替换行（见 8.1）
```

- v1 一次只打印**一个**值（D9 极简取向）；要打印多个值用插值：`print("{名字} {分数}")`。**（【规范补充】）**

**`数(值)` / `num`**——D3 的入口：把文本转成唯一的"数"：

```
print(数("95"))        # 95
print(数("3.5"))       # 3.5
print(数("九十五"))    # 错误，可被接住：文本 "九十五" 不是数字。你是不是想写 95？
```

**`文本(值)` / `str`**——与插值同一套转换规则：

```
print(文本(10))        # 10
print(文本(真))        # 真
print(文本([1, 2]))    # [1, 2]
```

**`列表(值)` / `list` 与 `字典(配对列表)` / `dict`**：

```
print(列表())                       # []
print(列表({"名字": "咪咪"}))        # ["名字"]
print(字典())                        # {}
print(字典([["名字", "咪咪"], ["饥饿", 0]]))   # {"名字": "咪咪", "饥饿": 0}
```

**`从a到b(a, b, 步长: 1)` / `range_to`**——D7 的核心：生成结果**看得见、能打印**：

```
print(从a到b(1, 5))          # [1, 2, 3, 4]
print(从a到b(1, 10))         # [1, 2, ..., 9]
print(从a到b(0, 10, 步长: 2)) # [0, 2, 4, 6, 8]
print(从a到b(5, 0, 步长: -1)) # [5, 4, 3, 2, 1]
```

- `从a到b(a, b)` 里 `a` 与 `b` 只是参数位的名字，实际传值即可。
- `步长` 为 `0` 报错；方向与步长不符（如 `从a到b(5, 0)`）得空列表 `[]`，**不报错**。**（【规范补充】）**

**`取(序列, 起: 0, 止: 省略, 步长: 1)` / `slice`**——替代切片语法：

```
名单 = ["小明", "小红", "小刚"]
print(取(名单, 0, 2))          # ["小明", "小红"]
print(取(名单, 1))             # ["小红", "小刚"]
print("卅语言"[0])           # 错误！文本也有索引，但取一段要用 取
print(取("卅语言", 0, 2))     # "卅"
```

**`长度(值)` / `len`**：

```
print(长度([1, 2, 3]))    # 3
print(长度("卅"))       # 2（一个汉字算一个字符）
print(长度({"a": 1}))     # 1
```

**`抛出(消息)` / `throw`**——与 `尝试/接住` 配套（D8）：

```
函数 文本转成绩(文本)
    尝试
        返回 数(文本)
    接住 错误信息
        抛出("成绩必须是数字，收到: {文本}")
    完毕
完毕

print(文本转成绩("95"))    # 95
```

**`输入(提示)` / `input`**：

```
名字 = 输入("你叫什么名字？")
print("你好, {名字}!")
```

### 6.4 类型成员函数（不占 30 个名额）

成员函数**存在的原因只有一条**：它们**原地修改**可变对象。全局函数一律返回新值，成员函数一律修改自身——这条分工让"会不会改到原来的东西"变成看一眼调用形式就知道的事。

| 值类型 | 成员 | 签名 | 一行说明 |
|---|---|---|---|
| 列表 | 添加 / append | `列表.添加(值)` | 在末尾追加一个元素（原地修改，返回空值）。 |
| 列表 | 去重 / dedupe | `列表.去重()` | 去掉重复元素、保留首次出现的顺序（原地修改，返回空值）；简报 D4 指定的"列表代替集合"写法。 |
| 字典 | 删除 / remove | `字典.删除(键)` | 删除某个键（原地修改，返回空值）；键不存在时报错并列出候选键。 |

```
数字们 = [3, 1, 3, 2]
数字们.去重()
print(数字们)          # [3, 1, 2]

小猫.删除("饥饿")
```

- 【规范补充】`添加/append` 与 `删除/remove` 是为"原地修改"补的两个成员，简报只显式提到 `列表.去重()`；是否收编请见第 9 节清单。
- 列表的元素顺序、字典的键顺序：v1 规定**字典保持插入顺序**（`列表(字典)`、遍历字典、`文本(字典)` 都按插入顺序），列表顺序就是字面顺序。**（【规范补充】）**

### 6.5 与内置函数配套的语法形式

标准库里唯一"不是函数"的能力，是错误处理，它为极简而被做成**语法**而不是对象（D8）：

```
尝试
    危险操作()
接住 错误信息
    print("出错了: {错误信息}")
完毕
```

- `尝试` / `接住` 是关键字（2.6 表），不是函数，因此**不能**写 `尝试(函数() => ...)`。
- 唯一的抛错方式是内置函数 `抛出("消息")`，没有 `raise` 语句。
- 其他语言里的 `finally`、`else`、错误类型匹配、自定义错误类，v1 **全部没有**；需要"无论如何都要做的事"，就把它写在 `尝试/接住` **之后**（因为错误一旦被接住，程序会继续往下走）。

## 7. 报错规范与示例（D10）

### 7.1 格式

```
第 <行号> 行：<中文说明><修复建议>
line <行号>: <English explanation><suggestion>
  <可选的上下文提示行>
```

硬性规则（来自 D10）：

1. **中文优先**，英文紧随其后，两行内容必须**语义相同**。
2. **必须带行号**（`第 N 行`）。
3. **必须给建议**：拼写错误给最接近的候选名；类型错误说明"期望什么、实际是什么"并给转换函数；标点错误说明"你打的是全角/中文符号"；缺收尾词指出**块从第几行开始**。
4. 用词口语化：不出现"未绑定的标识符""词法错误""token"这类术语；用"变量""还没有定义""这里应该是"。
5. **不泄露实现语言**：不出现 `Traceback`、`IndexError`、`NoneType` 等字样。
6. 未被接住的错误在消息之后追加**调用链**：

```
  调用位置：第 15 行，在函数 "总价" 中
  called from: line 15, in function "总价"
程序已停止。program stopped.
```

7. **缩进与空格问题永不报错**（D1）：多缩进、少缩进、空格 Tab 混用都不是错误，解释器不得为此产生任何提示。

## 8. 完整可运行示例（与简报第 3 节逐字一致）

以下三段是全部文档的基准示例，**写法不得改动**。

### 8.1 打印九九乘法表

```
# 打印九九乘法表
函数 乘法表()
    for i 于 从a到b(1, 10)
        for j 于 从a到b(1, i + 1)
            print("{j}×{i}={i * j}", 结尾: "  ")
        完毕
        print("")
    完毕
完毕

乘法表()
```

要点：嵌套 `for` 各用 `完毕` 收尾；`从a到b(1, 10)` 生成 1..9（不含 10）；命名实参 `结尾: "  "` 抵消换行；插值内可以做乘法 `{i * j}`。

### 8.2 用字典代替"对象"，用函数操作字典

```
# 用字典代替"对象"，用函数操作字典
小猫 = { "名字": "咪咪", "饥饿": 0 }

函数 喂食(动物)
    动物["饥饿"] = 动物["饥饿"] - 10
    返回 "{动物["名字"]} 吃饱啦，饥饿度 {动物["饥饿"]}"
完毕

print(喂食(小猫))
```

要点：没有类（D4），字典存字段；字典按引用传递，函数内的下标赋值对调用者可见（5.3）；插值表达式里可以写含双引号的文本字面量（5.5）。

### 8.3 尝试/接住 与 抛出

```
# 尝试/接住 与 抛出
函数 文本转成绩(文本)
    尝试
        返回 数(文本)
    接住 错误信息
        抛出("成绩必须是数字，收到: {文本}")
    完毕
完毕

print(文本转成绩("95"))    # 95
```

要点：`尝试/接住` 也是块，同样用 `完毕` 收尾（D8、D1）；错误对象就是一文本 `错误信息`；主动抛错用内置函数 `抛出`。

## 附：数据库/db 的 SQL 方言（v1.6/v1.8）

SQL 关键词中英双语、可整词连写或分词写、可与英文混用：

| 语义 | 中文 | 英文 |
|---|---|---|
| 建表 | 建 表（如无） | CREATE TABLE（IF NOT EXISTS） |
| 删表 | 删 表（如有） | DROP TABLE（IF EXISTS） |
| 插入 | 插入 … 值 | INSERT INTO … VALUES |
| 查询 | 选择 … 出 | SELECT … FROM |
| 条件 | 哪里；和 / 或 / 非 | WHERE；AND / OR / NOT |
| 排序 | 排序 按 … 升 / 降（序） | ORDER BY … ASC / DESC |
| 限量 | 限 | LIMIT |
| 更新 | 改 … 设 | UPDATE … SET |
| 删行 | 删行 | DELETE FROM |
| 自增列 | 自增 | AUTO_INCREMENT |
| 聚合 | 数 / 和 / 平均 / 最大 / 最小 | COUNT / SUM / AVG / MAX / MIN |

- `?` 是位置参数，按出现顺序编号绑定实参（逐行求值不重复计数）。
