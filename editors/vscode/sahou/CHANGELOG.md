# sahou（卅）VS Code 扩展 · 更新说明

扩展与语言本体同步演进；语言侧的变化见仓库根 `docs/`（00 简报为唯一事实来源）。

## 0.2.1（2026-09-20，随卅 v0.2.1）

- **stones 包元数据更新到十八包**：新增 罗马数字/分数库/矩阵库/时长库 的成员补全与悬停
  （`分数文本`/`矩阵文本` 等新成员名）。
- 随语言 v0.2.1 的服务端改进自动生效：`变量名.` 的补全现在给出列表/字典成员方法
  （添加/append、去重/dedupe、删除/remove），而不是无关关键词。
- 无界面变动；推荐所有 0.2.x 用户升级。

## 0.2.0（2026-09-19，随卅 v0.2）

**主题：编辑器生态基建 + 补全打通 + 语言图标**

- **上下文补全打通（最重要的修复）**：此前 `sahou lsp` 服务端早已提供上下文补全
  （`用 "…` 给 stones 包名、`名字.` 给模块/stones 成员），但扩展从未发送补全请求，
  只用静态表。现在输入 `.`、`"`、空格都会触发服务端补全（500ms 内响应优先采用），
  静态数据兜底——语言服务没启动时照样能补。
- **编辑器元数据共享化（多编辑器预留）**：新增 `editors/shared/language.json` 作为
  关键字/内置函数/模块/stones 包成员的**唯一事实来源**，本扩展读取它的同步副本
  `data/language.json`（`node editors/sync-shared.js` 重新同步）。
  详见 `editors/README.md`——为 JetBrains/Sublime/Vim 等新编辑器做集成不再需要重新整理资料。
- **语言图标**：
  - 扩展/市场图标 `icons/sahou-128.png`（流水线设计栅格化，`editors/tools/genicon.py` 生成）；
  - 新增「卅 (sahou)」**文件图标主题**：`.saho` 文件与 `stones.yml` 显示三颗石子图标，
    在 文件首选项→文件图标主题 里选择即可。
- **悬停文档增强**：内置函数带签名与"服务端/双端"标注；模块与 14 个 stones 包
  （含 v0.2 新增的 数列库/逻辑库/密码库/日期库）的成员悬停说明；管道占位符 `它` 有专门说明。
- **语法高亮补齐**：`跳出/继续/格子`（break/continue/cell）、内置函数 `位置/find`、
  模块 `数据库/网页/应用/测试`（db/html/app/assert）、管道运算符 `->`（含全角 `→`）、
  管道占位符 `它` 全部正确着色。
- **新命令**：
  - 「转译当前文件为 JS」（编辑器标题栏箭头按钮）：`sahou build <文件> -o <同名>.js`；
  - 「打开 sahou 交互环境（REPL）」。
- **新片段**：格子（响应式）、从a到b 循环、引入 stones 包；原有 12 个片段保留。
- **新增设置** `sahou.completion`（默认开）：总开关补全与悬停。
- **其他**：marketplace 元数据（repository、keywords）、MIT LICENSE 文件。
