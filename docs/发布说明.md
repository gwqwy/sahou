## v0.2.1（2026-09-20）

下载 `sahou.exe` 即可使用——**单文件自带全部 18 个 stones 标准库包与浏览器运行时**，无需安装。
推荐 Windows 10/11；浏览器运行时和 VS Code 扩展见项目仓库相应目录。

### 新增

- stones 标准库扩充到 **十八包**，新增 4 个纯卅库（`用 "包名" 引入` 免安装即用）：
  - **罗马数字**：1–3999 的数 ↔ 罗马数字文本（`到罗马(2026)` 得 `MMXXVI`）
  - **分数库**：精确分数运算——加/减/乘/除/化简/转小数/分数文本/带分数文本，有理数底层永不丢精度
  - **矩阵库**：矩阵加/乘/转置/单位矩阵/行列式（2×2、3×3）/矩阵文本
  - **时长库**：秒数 ↔ 时分秒——`时长文本(5025)` 得 `1时23分45秒`、`钟表文本` 得 `01:23:45`
- VS Code 扩展 **0.2.1**：十八包的成员补全与悬停文档；`变量名.` 现在给出列表/字典真实的成员方法
  （添加/append、去重/dedupe、删除/remove）

### 变更

- **输出提速**：`打印` 改为缓冲批量写出，循环打印的系统调用减少几个数量级；
  交互场景（服务器、窗口事件、输入提示）最迟 50ms 可见；REPL 与 `sahou 打包`
  生成的独立 exe 同享此提速
- `如果/当` 条件里误写单个 `=`（如 `如果 分数 = 60`）时，给出专门的双语提示
- LSP 补全：`名字.` 对非模块名给出值成员方法，而不是无关关键词

### 修复

- 多行字典字面量的**尾逗号**与**闭括号独立成行**（如 `}` 单独一行）不再报错（v4.2 起的解析缺陷）
- 转译器：与内置函数同名的局部变量/参数，现在与解释器同语义（此前 `位置` 这类名字会被
  错误替换成内置函数，运行时报"函数 和 数 没有大小之分"）
- 给内置函数名赋值或重定义内置函数，转译器现在与解释器一样在编译期拒绝
