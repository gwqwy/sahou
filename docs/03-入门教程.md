## 1. 5 分钟了解卅

### 1.1 卅是什么

**卅**（读音 sa），是一门"**比 Python 更简单一点的入门语言**"。

Python 是一条蟒蛇：庞大、有力、能吞下整个工程。"卅"是"三十"的古体字：三横一竖，四画写完，小、直、一眼就能写完。
它保留了 Python 里对初学者最有用的部分——**动态、灵活、可读**，同时砍掉了新手最容易踩坑的部分。

它的目标用户就是三类人：

- 第一次接触编程、还不知道"变量""函数"是什么的人；
- 中小学课堂里，课时有限、不能把一半时间花在解释缩进和浮点误差上的学生；
- 习惯用中文思考、希望先建立编程思维、再慢慢接触英文关键字的人。

### 1.2 为什么它更简单：五条"少一点"

**第一，用 `end`（或 `完毕`）收尾，不用数空格。**

在 Python 里，缩进（每行前面空几格）是语法的一部分。混用空格和 Tab、多缩进一格、复制粘贴后缩进错乱，
程序就完全跑不起来——而这些问题**跟你的程序逻辑毫无关系**。

卅不用缩进，用一个明确的词收尾：

```
如果 x > 3
    print("大")
否则
    print("小")
完毕
```

上面这段代码，你哪怕把 `print("大")` 顶格写，意思也完全一样。
缩进在卅里**只是给人看的排版**，不是语法。

**第二，中文英文都能写。**

每条语句都有等价的中文关键字：`if`/`如果`、`else`/`否则`、`elif`/`又如`、`while`/`当`、
`for`/`遍历`、`in`/`于`、`end`/`完毕`、`and`/`并且`、`or`/`或者`、`not`/`非`、
`true`/`真`、`false`/`假`、`null`/`空值`、`fn`/`函数`、`return`/`返回`、`let`/`设`。

你可以全中文写，全英文写，也可以混着写。它们是**同一套语法的两种拼写**，不是两门语言。

**第三，只有一种"数"。**

Python 里 `10` 和 `10.0` 是两个不同的类型，`10 / 3` 的结果在不同版本里还不一样，
`0.1 + 0.2` 甚至不等于 `0.3`。这些问题对第一周的学习者毫无价值，却要花掉大量课堂时间。

卅的答案是：**你根本看不到这个区分**。你永远只写 `10`、`3.5`；
`10 == 10.0` 成立；除法**永远是真除法**，`10 / 3` 就是 `3.3333...`。

**第四，只有 5 种数据类型。**

数、文本、列表、字典、布尔，再加一个空值。没有元组、没有集合、没有字节、没有复数，
也没有类（class）。需要"对象"的时候，用**字典 + 函数**就够了。

**第五，标准库极小，而且不用 import。**

常用能力全部内置、全局可见、名字一眼能懂，每个函数都有中英双名：
`print`/`打印`、`从a到b`、`数`、`文本`、`长度`、`取`、`询问`、`读取文件`、`抛出`。
总共不超过 30 个。

### 1.3 卅故意"不完整"

卅没有类、没有模块系统、没有并发、没有类型注解。这不是"暂时做不到"，
而是**主动画出的边界**：一门想让新手安心的语言，必须敢于说"这不是我现在要解决的问题"。

小练习：

1. 用自己的话说说：`end`/`完毕` 解决了 Python 的什么问题？
2. 卅里 `10 / 4` 等于多少？`10 == 10.0` 是真还是假？

<details>
<summary>参考答案</summary>

1. 它解决了"缩进（空格与 Tab 混用、层级错位）导致程序无法运行"的问题。
   块结构由明确的词标记，一眼能看出"这里结束了"，而不是靠数空格；缩进只作排版。
2. `10 / 4` 等于 `2.5`（除法永远是真除法，不做整除特例）；`10 == 10.0` 是 `真`，
   因为卅里根本不存在两个数类型，只有一种"数"。

</details>

## 2. 运行第一个程序

### 2.1 准备

1. 建立一个文件夹，比如 `E:\卅练习`。
2. 在里面新建一个文本文件，命名为 `hello.saho`（`.saho` 是卅源文件的扩展名）。
3. 用任何文本编辑器打开它——记事本就可以，不需要专门的 IDE。

### 2.2 写入并运行

把下面这一行写进去，保存：

```
print("你好，卅！")
```

在终端里（Windows 可以用 PowerShell）进入这个文件夹并运行解释器：

```text
cd E:\卅练习
sahou hello.saho
```

屏幕上会显示：

```text
你好，卅！
```

恭喜，你写出了第一个程序。

### 2.3 认识注释

以 `#` 开头的行是**注释**：写给人看的，解释器会完全忽略它。
你可以在注释里用中文随便写笔记，代码读起来会清楚很多。

```
# 这是我的第一个程序
# 作者：小明
print("你好，卅！")   # 行尾也可以写注释
```

### 2.4 一个程序的结构长什么样

看一个稍微完整一点的例子。它是**完整可运行**的：

```
# 示例 1：认识程序的样子
print("我正在学习卅语言")
print("我会数数：")
print(1)
print(2)
print(3)
print("数完了。")
```

运行结果：

```text
我正在学习卅语言
我会数数：
1
2
3
数完了。
```

几点值得注意：

- 程序**从上往下**，一行一行执行，顺序就是写字顺序。
- `print` 叫**内置函数**，它的作用是把括号里的东西显示到屏幕上。
- 文本要加引号 `"..."`，数不用加引号。
- 中文的 `打印("...")` 和 `print("...")` 完全等价。

再来看一个带判断的完整程序——先不用完全看懂：

```
# 示例 2：程序会"看情况"
设 天气 = "下雨"
如果 天气 == "下雨"
    print("记得带伞")
否则
    print("那就出门吧")
完毕
```

这段程序会打印 `记得带伞`。第 6、7 节的练习会让你彻底掌握它。

小练习：

1. 写一个程序，连续打印三行：你的名字、你的城市、你今天的心情。
2. 把示例 2 里的 `"下雨"` 改成 `"晴天"`，猜猜输出会变成什么，然后亲手验证一下。

<details>
<summary>参考答案</summary>

1.

```
# 我的自我介绍
print("我叫卅")
print("我住在杭州")
print("我今天心情很好")
```

2. 输出会变成 `那就出门吧`。因为 `天气 == "下雨"` 不成立，程序走 `否则` 这一支。
   这就是"程序会看情况"的含义：同一条程序，输入不同，走的路不同。

</details>

## 3. 变量与数

### 3.1 变量就是"贴了标签的盒子"

**变量**是用来存东西的盒子，盒子上面贴着一个名字。想存东西就"赋值"，想取东西就写名字。

```
设 年龄 = 12
print(年龄)
```

运行结果：

```text
12
```

`设`（英文 `let`）是**可选的**变量赋值前缀，写不写都可以。下面两行的效果完全一样：

```
设 年龄 = 12
年龄 = 12
```

变量名用中文、英文、下划线、数字都行（但不能用数字开头，也不能和关键字重名）。
推荐用一眼能读懂的中文名或英文名：`总价`、`次数`、`user_name`。

**一句话记住：`=` 不是"等于"，是"把右边放进左边"。**
判断"相等"要用 `==`，两个等号。

```
设 分数 = 60
分数 = 分数 + 10     # 取出原来的 60，加 10，再放回去
print(分数)          # 70
```

### 3.2 只有一种"数"

卅里只有一个数类型。你写 `10`、写 `3.5`、写 `0`，都是"数"。

```
# 示例 3：一个数就是全部的数
print(10)          # 10
print(3.5)         # 3.5
print(10 == 10.0)  # 真
print(10 / 3)      # 3.3333333333333335
print(10 / 4)      # 2.5
print(2 + 3 * 4)   # 14，先乘后加
print((2 + 3) * 4) # 20，括号优先
```

记住四条规则就够用了：

1. `+ - * /` 是加减乘除。
2. `/` **永远是真除法**：`10 / 4` 得 `2.5`，不会得 `2`。没有 `//` 这个运算符。
3. 括号 `( )` 可以改变计算顺序。
4. `==` 判断相等，`!=` 判断不等，`> < >= <=` 是大小比较，结果是 `真` 或 `假`。

比较的结果是**布尔**值，只有两个：`真`/`true`、`假`/`false`：

```
print(3 > 5)     # 假
print(3 != 5)    # 真
```

### 3.3 常见的计算写法

```
# 示例 4：算一笔账
设 单价 = 3.5
设 数量 = 4
设 总价 = 单价 * 数量
print(总价)                 # 14

设 余额 = 100
余额 = 余额 - 总价           # 花掉这笔钱
print("余额还剩", 余额)      # 余额还剩 86
```

注意最后一行：`print` 可以一次打印多个东西，中间用逗号隔开，输出时它们之间会有一个空格。
以后我们会用**插值**写出更漂亮的句子（第 4 节）。

小练习：

1. 设 `苹果单价 = 8`，`买了 = 3`，用变量算出总价并打印。
2. 设 `总钱数 = 25`，平均分给 2 个人，打印每人分到多少。想一想为什么结果不是 `12`。

<details>
<summary>参考答案</summary>

1.

```
设 苹果单价 = 8
设 买了 = 3
设 总价 = 苹果单价 * 买了
print(总价)          # 24
```

2.

```
设 总钱数 = 25
print(总钱数 / 2)    # 12.5
```

结果是 `12.5` 而不是 `12`，因为卅的 `/` 永远是**真除法**，不丢掉小数部分。
这正是 D3 的设计目的：少一条"什么时候会取整"的规则。

</details>

## 4. 文本与插值

### 4.1 文本（字符串）

**文本**就是用引号包起来的一串字符：`"你好"`、`"abc"`、`"123"`（注意这跟数 `123` 不同）。

文本可以用 `+` 拼接：

```
print("小" + "石")        # 卅
print("哈" + "哈" + "哈")  # 哈哈哈
```

但**推荐用插值**，因为它读起来就是一句完整的话。

### 4.2 插值：`"{表达式}"`

在文本里用花括号 `{ }` 包住变量或任意表达式，运行时会被替换成实际的值：

```
# 示例 5：插值让句子完整
设 名字 = "卅"
设 年龄 = 12
print("你好，{名字}！")                  # 你好，卅！
print("{名字}今年 {年龄} 岁。")           # 卅今年 12 岁。
print("明年就是 {年龄 + 1} 岁了。")       # 明年就是 13 岁了。
print("名字的长度是 {长度(名字)} 个字。")  # 名字的长度是 2 个字。
```

插值的三个好处：

1. **数字不用手动转换**。写成拼接就要 `"明年就是 " + 文本(年龄 + 1) + " 岁了。"`，多一层 `文本()`。
2. **引号和加号不会打架**。拼接写法里引号加号交替出现，很容易漏一个。
3. **句子不会被切碎**。读代码时你能直接读出中文语序。

花括号里可以放**任意表达式**，包括计算和函数调用：

```
设 单价 = 3.5
设 数量 = 4
print("总价是 {单价 * 数量} 元")            # 总价是 14 元
print("多买一件就是 {单价 * (数量 + 1)} 元")  # 多买一件就是 17.5 元
```

### 4.3 常见的文本操作

```
设 句子 = "卅很好学"

print(长度(句子))          # 5，长度是字符个数
print(取(句子, 0, 2))      # 卅，从第 0 个开始，取到第 2 个之前
print(句子 + "！")         # 卅很好学！
print(句子 == "卅很好学") # 真
```

关于 `取(文本, 起, 止)`：

- 位置（也叫**下标**）**从 0 开始数**：第 0 个是"小"。
- `起` 是要的开始位置，`止` 是**取到但不包括**的位置。
- `取(句子, 0, 2)` 取的是第 0、1 个字符，也就是"卅"。
- 卅没有 Python 的切片符号 `xs[1:3]`，一律用 `取(...)` 这个函数，参数含义写在位置上。

```
print(取(句子, 0, 1))   # 小
print(取(句子, 1, 3))   # 石很
```

### 4.4 类型转换

```
print(数("95"))       # 95，文本变数
print(数("95") + 5)   # 100，现在可以做加法了
print(文本(95))       # 95，数变文本
print(文本(95) + "分") # 95分
```

`文本(95)` 打印出来看起来还是 `95`，但它的类型是文本，所以能和别的文本拼接。
这是新手最容易混淆的一点：**看起来一样，不等于类型一样**。

小练习：

1. 设 `水果 = "苹果"`、`个数 = 6`、`单价 = 2.5`，用插值打印一句话：
   `6 个苹果一共 15 元`。
2. 设 `问候 = "你好世界"`，用 `取` 打印出 `好世`。

<details>
<summary>参考答案</summary>

1.

```
设 水果 = "苹果"
设 个数 = 6
设 单价 = 2.5
print("{个数} 个{水果}一共 {个数 * 单价} 元")
```

输出：`6 个苹果一共 15 元`。

2.

```
设 问候 = "你好世界"
print(取(问候, 1, 3))
```

第 0 个是"你"，第 1 个是"好"，第 2 个是"世"，所以 `取(问候, 1, 3)` 取出第 1、2 个字符，即 `好世`。

</details>

## 5. 列表与字典

卅只有 5 种数据类型：数、文本、列表、字典、布尔。上一节你已经见过数和文本，
这一节把剩下的两种一次学完。

### 5.1 列表：一串有顺序的东西

**列表**用方括号 `[ ]` 写，元素之间用逗号隔开。

```
设 水果 = ["苹果", "香蕉", "橘子"]
print(水果)          # ["苹果", "香蕉", "橘子"]
print(水果[0])       # 苹果，下标从 0 开始
print(水果[2])       # 橘子
print(长度(水果))     # 3
```

**下标从 0 开始**是编程世界的通行习惯，请务必记住：

| 元素 | 苹果 | 香蕉 | 橘子 |
|---|---|---|---|
| 下标 | 0 | 1 | 2 |

列表可以装任何类型，也可以混着装：

```
设 混合 = [1, "二", 3.5, 真]
print(混合[1])       # 二
```

往列表里加东西，用 `+ [新元素]`（这会产生一个新列表）：

```
设 购物车 = []
购物车 = 购物车 + ["牛奶"]
购物车 = 购物车 + ["面包"]
print(购物车)        # ["牛奶", "面包"]
print(长度(购物车))   # 2
```

修改已有元素，直接给下标赋值：

```
购物车[0] = "酸奶"
print(购物车)        # ["酸奶", "面包"]
```

从列表里取一段，用 `取`：

```
设 数字 = [10, 20, 30, 40, 50]
print(取(数字, 1, 4))   # [20, 30, 40]
```

### 5.2 字典：一对一对的"名字 → 值"

**字典**用花括号 `{ }` 写，里面是"键: 值"的配对。它适合表示"一个有若干个属性的东西"。

```
设 小猫 = { "名字": "咪咪", "饥饿": 0 }
print(小猫["名字"])     # 咪咪
print(小猫["饥饿"])     # 0

小猫["饥饿"] = 10       # 改一下（喂饱一点）
print(小猫["饥饿"])     # 10
```

字典的**键通常是文本**，值可以是任何类型——数、文本、列表，甚至另一个字典。

```
设 学生 = {
    "姓名": "卅",
    "年龄": 12,
    "爱好": ["画画", "编程"],
    "在读": 真
}
print("{学生["姓名"]} 今年 {学生["年龄"]} 岁")
print("爱好有：" + 文本(学生["爱好"]))
```

注意嵌套引号：`"{学生["姓名"]}"` 里外层是双引号，内层也是双引号，卅能正确识别
哪一对引号包着整个文本、哪一对在花括号里面。

### 5.3 用字典代替"对象"

这是卅一个重要的取舍：**没有类（class）**。

在 Python 里要写 `class`、`__init__`、`self`、继承……一整套语法。在卅里，
结构化数据就用字典表示，操作它的行为就用函数表示。看简报里的标准示例：

```
# 示例 6：用字典代替"对象"，用函数操作字典
小猫 = { "名字": "咪咪", "饥饿": 0 }

函数 喂食(动物)
    动物["饥饿"] = 动物["饥饿"] - 10
    返回 "{动物["名字"]} 吃饱啦，饥饿度 {动物["饥饿"]}"
完毕

print(喂食(小猫))
```

运行结果：

```text
咪咪 吃饱啦，饥饿度 -10
```

（饥饿度变成 -10，是因为我们把它从 0 减了 10。你可以在练习里修好这个小 bug。）

把这段程序拆开看：

- `小猫` 是一个字典，有两个键：`名字` 和 `饥饿`。
- `函数 喂食(动物)` 定义了一个函数，它接受一个参数 `动物`。
  传进来的实参是 `小猫`，所以在函数里 `动物` 就是那个字典。
- `动物["饥饿"] = 动物["饥饿"] - 10` 修改字典里的值。
- `返回` 把一句拼好的文本交回给调用者。
- 最后 `print(喂食(小猫))` 把返回值打印出来。

**字典 + 函数**，就足以表达入门阶段绝大多数"有数据、有行为"的程序，
而且没有 `self`、没有继承、没有构造函数的语法负担。

## 6. 条件：让程序做选择

### 6.1 `如果 / 又如 / 否则 / 完毕`

```
# 示例 7：判断成绩等级
设 分数 = 85

如果 分数 >= 90
    print("优秀")
又如 分数 >= 80
    print("良好")
又如 分数 >= 60
    print("及格")
否则
    print("要加油")
完毕
```

运行结果：

```text
良好
```

规则：

- `如果` 后面跟一个条件，**不加括号也完全可以**；条件后面**不写冒号**。
- 用 `完毕`（或 `end`）收尾，块里缩进多少格随意。
- `又如` 相当于英文的 `elif`，从上往下**依次**检查，第一个成立的分支执行，
  后面的分支**全部跳过**。
- `否则` 是兜底，前面的都不成立才走它。
- 分支可以有任意多个 `又如`，也可以没有。

上面这段把 `分数` 改成 `95` 会打印"优秀"，改成 `50` 会打印"要加油"。

### 6.2 条件怎么写

条件是一段能算出 `真` 或 `假` 的表达式。

| 写法 | 含义 |
|---|---|
| `a == b` | 相等（注意是两个等号） |
| `a != b` | 不相等 |
| `a > b` / `a < b` | 大于 / 小于 |
| `a >= b` / `a <= b` | 大于等于 / 小于等于 |
| `条件1 并且 条件2` | 两个都成立才为真（英文 `and`） |
| `条件1 或者 条件2` | 有一个成立就为真（英文 `or`） |
| `非 条件` | 反过来（英文 `not`） |

`并且`、`或者`、`非` 可以和比较混用，用小括号把意图写清楚：

```
设 年龄 = 15
设 有票 = 真

如果 年龄 >= 12 并且 有票
    print("可以入场")
否则
    print("不能入场")
完毕

如果 非 有票
    print("请先去买票")
完毕
```

一个常见陷阱：`非` 的优先级很高，所以取反一个比较时**要加括号**。
`非 有票 == 真` 会被理解成 `(非 有票) == 真`，这不是你想要的写法；
直接写 `非 有票` 就好。

### 6.3 真值：什么算"真"

在卅里，判断条件时会自动做"真值转换"：

| 值 | 算作 |
|---|---|
| `真` | 真 |
| `假` | 假 |
| 数 `0` | 假 |
| 其他数（含负数） | 真 |
| 空文本 `""` | 假 |
| 其他文本 | 真 |
| 空列表 `[]` | 假 |
| 非空列表 | 真 |
| 空字典 `{}` | 假 |
| 非空字典 | 真 |
| `空值` / `null` | 假 |

所以空列表可以直接当条件用：

```
设 购物车 = []
如果 购物车
    print("购物车里有 {长度(购物车)} 件东西")
否则
    print("购物车是空的")
完毕
```

输出 `购物车是空的`。**规则是统一的：空和零为假，其余为真**——不需要背特例。

   换个题目：设 `温度 = 30`，如果大于 28 打印"热"，否则打印"凉快"。
2. 设 `密码 = "stone"`，如果密码等于 `"stone"` 打印"登录成功"，
   如果是空文本则打印"密码不能为空"，否则打印"密码错误"。

## 7. 循环：让程序做重复的事

卅只有两种循环。这已经足够了。

### 7.1 `遍历 ... 于 ...`：把一个列表走一遍

```
# 示例 8：遍历列表
设 水果 = ["苹果", "香蕉", "橘子"]

for 一个 于 水果
    print("我爱吃{一个}")
完毕
```

运行结果：

```text
我爱吃苹果
我爱吃香蕉
我爱吃橘子
```

`for 一个 于 水果` 的意思是：**依次**把列表里的每个元素取出来，装进变量 `一个`，
然后执行一次循环体；列表走完，循环结束。`完毕` 是这个循环的结束标记。

英文和中文混用完全没问题：`for 一个 于 水果` 和 `遍历 一个 于 水果` 是同一句话。

### 7.2 `从a到b(起, 止, 步长)`：生成一串数

想"重复 10 次"的时候，先造一个列表：

```
for i 于 从a到b(1, 6)
    print(i)
完毕
```

运行结果：

```text
1
2
3
4
5
```

**重要：`从a到b(1, 6)` 生成的是从 1 开始、到 6 之前结束的列表，也就是
`[1, 2, 3, 4, 5]`，不包括 6。** 这个"包含起点、不包含终点"的规则和 `取` 是一致的。

三个参数都支持：

```
print(从a到b(1, 6))         # [1, 2, 3, 4, 5]
print(从a到b(0, 10, 2))     # [0, 2, 4, 6, 8]
print(从a到b(5, 0, -1))     # [5, 4, 3, 2, 1]
```

注意 `从a到b(...)` 返回的是一个**看得见的列表**——你可以把它打印出来，
这是它比 Python 的 `range` 更友好的地方。

遍历下标、同时拿到下标和值，需要自己写一点：

```
设 名字表 = ["卅", "小明", "小红"]

for i 于 从a到b(0, 长度(名字表))
    print("{i + 1} 号选手：{名字表[i]}")
完毕
```

运行结果：

```text
1 号选手：卅
2 号选手：小明
3 号选手：小红
```

### 7.3 `当 条件`：只要条件成立就一直做

```
# 示例 9：倒计时（完整可运行）
设 剩余 = 5

while 剩余 > 0
    print("{剩余}...")
    剩余 = 剩余 - 1
完毕
print("出发！")
```

运行结果：

```text
5...
4...
3...
2...
1...
出发！
```

用 `当`（英文 `while`）时的**铁律**：循环体里必须有让条件最终变成假的语句
（这里是 `剩余 = 剩余 - 1`）。否则程序会永远转下去。

### 7.4 用显式循环构建新列表

Python 有"列表推导式"这种一行生成新列表的写法，卅**故意没有**。
需要新列表，就老老实实写循环：

```
# 示例 10：每个数平方，装进新列表
设 平方数 = []

for i 于 从a到b(1, 6)
    平方数 = 平方数 + [i * i]
完毕

print(平方数)     # [1, 4, 9, 16, 25]
```

写起来比推导式长一点，但**每一步都看得见**：起手一个空列表，每次循环往里加一个。
入门阶段，理解时间远比打字时间值钱。

### 7.5 `print` 的 `结尾:` 参数

`print` 默认每次输出后换行。用命名参数 `结尾:` 可以改掉它：

```
for i 于 从a到b(1, 4)
    print(i, 结尾: " ")
完毕
print("")
```

运行结果：

```text
1 2 3
```

（`print("")` 打印一个空行，用来收尾。）这个参数在打印九九乘法表时特别有用，
也就是简报里的那段标准示例：

```
# 打印九九乘法表
函数 乘法表()
    for i 于 从a到b(1, 10)
        for j 于 从a到b(1, i + 1)
            print("{j}×{i}={i * j}", 结尾: "  ")
        完毕
        print("")
    完毕
完毕

乘法表()
```

小练习：

2. 用 `当` 循环打印 `10` 到 `1`，最后打印 `发射！`。

<details>
<summary>参考答案</summary>

1.

```

    print(一个 * 2)
完毕
```

## 8. 函数：给一段代码起个名字

### 8.1 定义与调用

**函数**是一段被起了名字的代码。定义一次，可以反复使用。

```
# 示例 11：定义并使用函数
函数 打招呼(名字)
    返回 "你好，{名字}！"
完毕

print(打招呼("卅"))     # 你好，卅！
print(打招呼("小明"))     # 你好，小明！
```

拆开看：

- `函数 打招呼(名字)` 是**定义**：函数名叫 `打招呼`，它接受一个参数 `名字`。
- 缩进的那一行是**函数体**。
- `返回`（英文 `return`）把结果交给调用者，并**立刻结束**函数。
- `完毕` 结束函数定义。
- `打招呼("卅")` 是**调用**：把 `"卅"` 传进去，得到返回值。

英文写法 `fn` 和中文 `函数` 完全等价：

```
fn 加(a, b)
    return a + b
end

print(加(3, 4))     # 7
```

卅里**定义函数只有这一种写法**。没有装饰器、没有默认参数、没有 `*args`。
阅读代码时，你永远不需要先辨认这是哪种语法变体。

### 8.2 参数与返回值

函数可以有零个、一个或多个参数：

```
函数 欢迎()
    返回 "欢迎光临卅餐厅"
完毕

函数 平均分(总数, 人数)
    返回 总数 / 人数
完毕

print(欢迎())             # 欢迎光临卅餐厅
print(平均分(100, 4))      # 25
```

没有 `返回` 的函数，调用后会得到 `空值`（英文 `null`）。这类函数通常是为了"做事"
而不是"算出东西"：

```
函数 报时(小时)
    print("现在是 {小时} 点")
完毕

报时(9)      # 现在是 9 点
```

### 8.3 函数里的变量是"局部"的

函数内部新设的变量，出了函数就消失了：

```
函数 算一算()
    设 秘密 = 42
    返回 秘密
完毕

print(算一算())   # 42
print(秘密)       # 出错：变量 "秘密" 还没有定义
```

卅会给出说人话的报错：

```text
第 8 行：变量 "秘密" 还没有定义。你是不是想写 "算一算"？
```

这就是 D10 的目标：报错同时告诉你**哪里错、为什么错、怎么改**。

### 8.4 函数是一等公民

函数可以像数据一样被赋值、传参、返回。而且有一个简短的匿名写法：
`函数(参数) => 表达式`。

```
# 示例 12：匿名函数与把函数当参数
设 翻倍 = 函数(x) => x * 2
print(翻倍(21))         # 42

函数 应用(操作, 值)
    返回 操作(值)
完毕

print(应用(函数(x) => x + 100, 5))   # 105
```

`函数(x) => x * 2` 读作"给一个 x，返回 x * 2"。这是卅里**唯一**的匿名函数语法
（Python 的 `lambda` 只有这一种形态被保留下来）。

小练习：

1. 写一个函数 `面积(长, 宽)`，返回长方形的面积，并算出 3 乘 5 的结果。
2. 写一个函数 `是大人(年龄)`，年龄大于等于 18 返回 `真`，否则返回 `假`。

<summary>参考答案</summary>

```

    返回 长 * 宽
完毕

```

2.

```

    返回 年龄 >= 18
```

## 9. 尝试 / 接住：出错也不怕

### 9.1 出错了会怎样

有些操作会失败，比如把不能变成数字的文本转成数：

```
print(数("你好"))
```

卅会报错并停止程序，报错信息是中文优先、带行号、带建议的。

但有时候你**希望程序不要崩**：用户输入错了，你希望提示他重来，而不是整个程序退出。
这就要用 `尝试 / 接住`。

### 9.2 `尝试 / 接住 错误信息 / 完毕`

```
# 示例 13：安全地做除法
函数 安全相除(a, b)
    尝试
        返回 a / b
    接住 错误信息
        返回 "算不出来：{错误信息}"
    完毕
完毕

print(安全相除(10, 2))    # 5
print(安全相除(10, 0))    # 算不出来：...(出错说明)
```

规则很简单：

- `尝试` 块里的代码正常执行。
- 一旦其中某一行出错，**后面几行立刻跳过**，直接跳到 `接住` 块。
- `接住 错误信息` 后面的名字（这里叫 `错误信息`）会拿到错误的说明文字。
- `完毕` 收尾。

错误对象**就是一个文本**（或者一个含 `.消息` 字段的简单字典）。
没有 `finally`，没有异常类继承树，没有"我该接住哪一个"的选择困难。

### 9.3 主动抛错：`抛出("消息")`

有时候不是程序出错了，而是**你想告诉调用者"这样用不对"**。用 `抛出`：

```
# 示例 14：尝试 / 接住 与 抛出
函数 文本转成绩(文本)
    尝试
        返回 数(文本)
    接住 错误信息
        抛出("成绩必须是数字，收到: {文本}")
    完毕
完毕

print(文本转成绩("95"))     # 95
print(文本转成绩("优秀"))   # 抛出：成绩必须是数字，收到: 优秀
```

这段就是简报里的标准写法：先在 `尝试` 里试一下，失败了就 `抛出` 一句
**人能看懂的话**——而不是把原始的错误信息原样丢给用户。

### 9.4 一个更实用的例子

```
# 示例 15：让用户反复输入，直到输入正确
设 成绩 = 空值
设 成功 = 假

while 非 成功
    设 输入 = 询问("请输入成绩：")
    尝试
        成绩 = 数(输入)
        成功 = 真
    接住 错误信息
        print("「{输入}」不是数字，请重新输入。")
    完毕
完毕

print("记录成功：{成绩} 分")
```

（`询问("提示")` 是内置函数，用来读取用户输入的一行文字，返回文本。）

这段程序的结构值得记住：

- 用 `成功` 这个布尔旗标控制循环；
- `尝试` 里做可能失败的事，一旦成功就把旗标翻成 `真`，循环自然结束；
- `接住` 里只负责提示，不中断程序。

小练习：

1. 写一个函数 `安全转数(文本)`：能转成数就返回那个数，否则返回 `0`。
2. 写一个函数 `除法(甲, 乙)`：如果乙是 `0`，就 `抛出("除数不能为 0")`。

<details>
<summary>参考答案</summary>

1.

```

    尝试
        返回 数(文本)
    接住 错误信息
        返回 0
    完毕
完毕

print(安全转数("哈哈"))   # 0
```

2.

```

        抛出("除数不能为 0")
    完毕

完毕

print(除法(10, 0))     # 抛出：除数不能为 0
```

注意 `抛出` 也可以写在 `尝试` 块**外面**。它的作用是"报告一个错误"，
至于谁来接住，由调用者决定。

</details>

## 10. 综合小项目：命令行记账本

现在把前面学的东西全部用上，写一个**完整可运行**的小程序。

### 10.1 需求

一个命令行记账本，支持四个操作：

| 输入 | 作用 |
|---|---|
| `1` | 记一笔账（输入说明和金额） |
| `2` | 查看所有账目和累计总额 |
| `3` | 撤销最后一笔 |
| `0` | 退出 |

### 10.2 先想清楚数据怎么存

卅没有类，我们用**两个平行的列表**来存账目——虽然也能用字典，
但平行列表对初学者来说更直观：

```
设 说明表 = []     # ["早饭", "打车", ...]
设 金额表 = []     # [12, 25.5, ...]
```

两个列表**同一下标**上的东西属于同一笔账：`说明表[0]` 和 `金额表[0]` 是第一笔。

### 10.3 完整代码

```
# ============================================
# 卅记账本 v1
# 运行：sahou jizhang.saho
# ============================================

设 说明表 = []
设 金额表 = []

# ---------- 记一笔账 ----------
函数 记一笔()
    设 说明 = 询问("这笔钱花在哪：")
    尝试
        设 金额 = 数(询问("花了多少："))
        说明表 = 说明表 + [说明]
        金额表 = 金额表 + [金额]
        print("已记录：{说明} {金额} 元")
    接住 错误信息
        print("金额必须是数字，这笔没有记上。")
    完毕
完毕

# ---------- 统计总额 ----------
函数 算总额()
    设 合计 = 0
    设 i = 0
    while i < 长度(金额表)
        合计 = 合计 + 金额表[i]
        i = i + 1
    完毕
    返回 合计
完毕

# ---------- 查看账目 ----------
函数 看账目()
    如果 长度(说明表) == 0
        print("还没有记过账。")
        返回 空值
    完毕

    print("------ 账目明细 ------")
    for i 于 从a到b(0, 长度(说明表))
        print("{i + 1}. {说明表[i]}  {金额表[i]} 元")
    完毕
    print("----------------------")
    print("共 {长度(说明表)} 笔，合计 {算总额()} 元")
完毕

# ---------- 撤销最后一笔 ----------
函数 撤销()
    设 笔数 = 长度(说明表)
    如果 笔数 == 0
        print("没有可撤销的账目。")
        返回 空值
    完毕

    说明表 = 取(说明表, 0, 笔数 - 1)
    金额表 = 取(金额表, 0, 笔数 - 1)
    print("已撤销最后一笔，现在共 {长度(说明表)} 笔。")
完毕

# ---------- 主循环 ----------
函数 主程序()
    print("欢迎使用卅记账本")
    print("1 记账   2 查看   3 撤销   0 退出")

    设 运行中 = 真
    while 运行中
        设 命令 = 询问("请输入编号：")

        如果 命令 == "1"
            记一笔()
        又如 命令 == "2"
            看账目()
        又如 命令 == "3"
            撤销()
        又如 命令 == "0"
            print("再见！")
            运行中 = 假
        否则
            print("看不懂「{命令}」，请输入 1、2、3 或 0。")
        完毕
    完毕
完毕

主程序()
```

### 10.4 逐块拆解

**`记一笔()`**：用 `询问` 拿说明和金额。金额是文本，必须用 `数(...)` 转成数；
转不了会出错，所以整段包在 `尝试 / 接住` 里——这样用户打错字不会让程序崩掉。

**`算总额()`**：用 `当 i < 长度(金额表)` 走一遍列表。这里必须自己维护 `i`，
也必须写 `i = i + 1`，否则就是死循环。`合计` 从 `0` 开始，每次加一个。

**`看账目()`**：先处理"一笔都没有"的特殊情况，用 `返回 空值` 提前退出。
然后 `遍历 i 于 从a到b(0, 长度(说明表))`，用 `i + 1` 当人类习惯的编号
（列表下标从 0 开始，但给人看的时候从 1 开始更自然）。

**`撤销()`**：`取(说明表, 0, 笔数 - 1)` 取"从第 0 个到倒数第一个之前"的部分，
正好丢掉最后一个元素。

**`主程序()`**：一个 `当 运行中` 的主循环，用 `如果 / 又如 / 否则` 分派命令。
注意 `询问` 返回的是**文本**，所以和 `"1"` 比较时要用引号，不能写 `1`——
这是新手最常犯的错误之一。

## 11. 综合小项目二：猜数字

### 11.1 版本一：不需要输入，纯逻辑版

先看一个**不需要任何输入**的版本——它用固定顺序的猜测，方便你直接跑起来、
看清循环和判断怎么配合：

```
# 示例 16：猜数字（固定答案版）
设 目标 = 42
设 猜过 = [10, 50, 42]
设 位置 = 0
设 猜中 = 假

while 位置 < 长度(猜过) 并且 非 猜中
    设 猜 = 猜过[位置]
    print("我猜 {猜}")

    如果 猜 == 目标
        print("猜对了！")
        猜中 = 真
    又如 猜 > 目标
        print("太大了")
    否则
        print("太小了")
    完毕

    位置 = 位置 + 1
完毕
```

运行结果：

```text
我猜 10
太小了
我猜 50
太大了
我猜 42
猜对了！
```

### 11.2 版本二：会跟你玩的完整版

现在换成真实交互，加上"最多猜 5 次"的规则。

这里有一个需要动脑子的地方：**如果用户输入的不是数字，这次不该算作一次猜测**。
第 9.4 节示例 15 已经给了解法——把"反复问、直到拿到一个数"这件事单独做成一个函数，
让它内部用 `当 非 成功` 循环。这样主循环里每次拿到的一定是数，逻辑就干净了。

卅 v1 的循环**没有** `break` / `continue` 这类跳转语句，这是刻意的取舍：
**循环只有两种，跳转越少，控制流越容易读**。所以遇到"跳过这一轮"的需求，
正确的做法不是找跳转语句，而是**把那个步骤收进一个函数**——这也是函数存在的意义。

```
# ============================================
# 卅猜数字（完整可运行）
# 运行：sahou caishuzi.saho
# ============================================

函数 读一个数(提示)
    设 结果 = 空值
    设 成功 = 假
    while 非 成功
        设 输入 = 询问(提示)
        尝试
            结果 = 数(输入)
            成功 = 真
        接住 错误信息
            print("「{输入}」不是数字，请重新输入。")
        完毕
    完毕
    返回 结果
完毕

函数 开始游戏()
    设 目标 = 42
    设 最多次数 = 5
    设 已猜次数 = 0
    设 猜中 = 假

    print("我想好了一个 1 到 100 之间的数，你有 {最多次数} 次机会。")

    while 已猜次数 < 最多次数 并且 非 猜中
        设 猜 = 读一个数("第 {已猜次数 + 1} 次猜测：")
        已猜次数 = 已猜次数 + 1

        如果 猜 == 目标
            print("猜对了！你用了 {已猜次数} 次。")
            猜中 = 真
        又如 猜 > 目标
            print("太大了，往小猜。")
        否则
            print("太小了，往大猜。")
        完毕
    完毕

    如果 非 猜中
        print("次数用完了。答案是 {目标}。")
    完毕
完毕

开始游戏()
```

### 11.3 运行示例

```text
我想好了一个 1 到 100 之间的数，你有 5 次机会。
第 1 次猜测：50
太大了，往小猜。
第 2 次猜测：abc
「abc」不是数字，请重新输入。
第 2 次猜测：25
太小了，往大猜。
第 3 次猜测：42
猜对了！你用了 3 次。
```

### 11.4 这段程序教了你什么

- **函数的复用**：`读一个数` 被反复调用，每次都能保证拿到的确实是数。
- **布尔旗标**：`猜中` 既控制循环，又用来在循环结束后判断是赢是输。
- **组合条件**：`已猜次数 < 最多次数 并且 非 猜中`——两个条件同时成立才继续。
- **错误处理不是终点**：`接住` 之后程序继续跑，用户体验不会中断。

小练习：

1. 把"最多 5 次"改成"最多 3 次"，并把目标改成 7，手工验证输出。
2. 给猜数字加上提示：如果猜的数与目标的差不超过 3，就多打印一句"很接近了！"。

<details>
<summary>参考答案</summary>

1. 把 `设 最多次数 = 5` 改成 `设 最多次数 = 3`，把 `设 目标 = 42` 改成 `设 目标 = 7`。
   你会得到最多 3 次机会，超过就打印"次数用完了。答案是 7。"。

2. 在判断里加一个分支即可（用差值判断远近）：

```
    设 差距 = 猜 - 目标
    如果 差距 < 0
        差距 = 0 - 差距
    完毕

    如果 猜 == 目标
        print("猜对了！")
    否则
        如果 差距 <= 3
            print("很接近了！")
        完毕
        如果 猜 > 目标
            print("太大了，往小猜。")
        否则
            print("太小了，往大猜。")
        完毕
    完毕
```

这里用 `0 - 差距` 把负数变正数，因为卅没有内置的绝对值函数——
正好体会一下"内置函数很少"意味着什么：**少，但够用；需要什么，就自己写一个函数。**

</details>

## 12. 接下来学什么

恭喜你，你已经把入门的全部核心概念走了一遍：

| 概念 | 关键字 / 函数 | 在哪一节 |
|---|---|---|
| 输出 | `print` / `打印` | 2 |
| 变量 | `设` / `let`（可省略） | 3 |
| 唯一的数类型 | `+ - * / == != > < >= <=` | 3 |
| 文本与插值 | `"{表达式}"`、`长度`、`取`、`数`、`文本` | 4 |
| 列表 | `[ ]`、下标、`+ [x]`、`取` | 5 |
| 字典 | `{ "键": 值 }`、`d["键"]` | 5 |
| 条件 | `如果` / `又如` / `否则` / `完毕` | 6 |
| 循环 | `遍历 x 于 列表`、`当 条件`、`从a到b` | 7 |
| 函数 | `函数` / `fn`、`返回` / `return`、`函数(x) => 表达式` | 8 |
| 错误处理 | `尝试` / `接住` / `抛出` | 9 |

### 12.1 三件建议

1. **把练习都做一遍**。读懂和写出来是两种能力，只有后者会长在你身上。
2. **改坏你的程序**。把 `完毕` 删掉一个、把 `==` 写成 `=`、把文本和数相加，
   然后读一读卅给你的报错——报错也是教学内容（D10）。
3. **用中文写，慢慢过渡到英文**。等你觉得中文关键字变啰嗦了，
   就换成 `if`/`for`/`fn`/`end`，你会发现学到的逻辑完全不用重学。

### 12.2 你还没学到、但已经够用的部分

卅的标准库**不超过 30 个内置函数**，全部小写蛇形命名、全局可见、中英双名：

- `print` / `打印`：输出
- `询问`：读入一行文本
- `从a到b(起, 止, 步长)`：生成列表
- `长度(东西)`：长度
- `取(列表或文本, 起, 止)`：取一段
- `数(文本)` / `文本(数)`：类型转换
- `抛出("消息")`：报告错误
- `读取文件(路径)`：读文件

以后你会用到的还有列表的 `去重()` 等少量能力，以及 v2 才可能出现的
`用 "xxx" 引入` 模块系统。**现在这些都不需要**：单文件程序是入门的主场景，
能用一个文件写清楚的东西，不需要引入任何模块。

### 12.3 最后的提醒

卅故意不完整：没有类、没有模块、没有并发、没有类型注解。
它把语法预算几乎全部花在了**容错**和**报错**上——可以为多打一个 `完毕` 付费，
不肯为缩进对齐付费；可以为多写一个循环付费，不肯为读懂一个推导式付费。

先写得出来，再写得好。祝你玩得开心。
