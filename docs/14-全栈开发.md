# 15 · 全栈开发（v1.6：表单 / 会话 / 静态文件 / 网页渲染 / 数据库）

> 读者：初学者 → 实现者。本章对应 PHP 的"一种语言写完整网站"体验：
> 表单提交（`$_POST`）、会话（`$_SESSION`）、Cookie、静态文件、服务端渲染 HTML、嵌入式数据库（SQLite/PDO 对应物）。
> 综合示例：`examples/留言板.saho`（可直接运行）。

## 1. 请求字典里新添的键

v1.1 的请求字典有 `方法/路径/查询/头/体`。v1.6 新增：

| 键 | 内容 | PHP 对应物 |
|---|---|---|
| `请求["表单"]` | POST 表单 + 查询串合并的字典（`application/x-www-form-urlencoded` 与 `multipart/form-data` 都解析） | `$_REQUEST` |
| `请求["Cookie"]` | 请求带来的 Cookie 字典 | `$_COOKIE` |
| `请求["会话"]` | 会话字典：改它就改了这次会话，下次请求（带同一 Cookie）还能读到 | `$_SESSION` |

会话无需初始化：第一次访问自动发一个 `卅_sid` Cookie 并建好空会话字典。

## 2. 服务的新成员

- `服务.静态(前缀, 目录)`：把 URL 前缀映射到本地目录直接发文件。
  例：`服务.静态("/静态/", "静态文件")` → `/静态/图标.svg` 发 `静态文件/图标.svg`。
- 响应字典新增便捷键 `"Cookie"`：字典里每个键值自动变成一条 `Set-Cookie`。
  例：`返回 {"Cookie": {"次数": "1"}, "体": "好"}`。
- **会话落盘**（v1.8）：`服务.会话存("会话.json")` 把会话字典持久化到文件，
  服务重启后会话不丢；**24 小时无活动即过期**，过期的会话不复活（当作新访客）。
- **文件上传**（v1.8）：`multipart/form-data` 里的文件自动存入临时目录，
  `请求["文件"]["字段名"]` 是一个字典：`文件名` / `路径` / `大小`。
- **服务器默认超时**（v1.8）：读请求头 10 秒、读整体请求 30 秒、写响应 60 秒、
  空闲（keep-alive）120 秒——慢客户端不会拖垮服务。

## 3. 网页模块（网页/html）：服务端渲染

- `网页.渲染(模板, 数据)`：模板里 `[[键]]` 取值并**自动 HTML 转义**（防注入，默认安全）；
  `[[[键]]]` 原样输出（只用于可信内容）。键支持嵌套：`[[用户.名字]]`。
- `网页.转义(文本)`：只转义，不套模板。

```saho
体 = 网页.渲染("<h1>你好，[[名字]]</h1>", {"名字": "<b>小明</b>"})
# 体 = <h1>你好，&lt;b&gt;小明&lt;/b&gt;</h1>
```

> 为什么不用 `{{ }}`？语言字符串插值已占用花括号（`"{表达式}"`），模板语法用双方括号。

## 4. 数据库模块（数据库/db）：纯 Go 嵌入式 SQL

零依赖（不装 SQLite 也能用），整个库存进一个 JSON 文件，每次写操作即时落盘。

```saho
库 = 数据库.打开("数据.db")
库.执行("建 表 如无 用户 (名字, 年龄)")                    # 建表（已存在则跳过）
库.执行("插入 用户 (名字, 年龄) 值 (?, ?)", "小明", 10)     # 插入，? 按序绑参数
库.执行("改 用户 设 年龄 = ? 哪里 名字 = ?", 11, "小明")    # 更新
库.执行("DELETE FROM 用户 哪里 名字 = ?", "老王")           # 删行
名单 = 库.查询("选择 * 出 用户 哪里 年龄 > ? 排序 按 年龄 降 限 10", 5)
print(库.表())      # ["用户"] —— 所有表名
库.关闭()           # 显式落盘收尾（写操作本来就即时落盘）
```

### 成员一览

| 成员 | 返回 | 说明 |
|---|---|---|
| `库.执行(sql, 参数...)` | 数（受影响行数） | 建表/插入/更新/删行/删表 |
| `库.查询(sql, 参数...)` | 列表（每行是字典） | 只能跑 选择/SELECT |
| `库.表()` | 列表 | 所有表名 |
| `库.关闭()` | 空值 | 显式落盘 |

### SQL 子集（中英双语关键词，可混写）

| 语句 | 中文写法 | 英文写法 |
|---|---|---|
| 建表 | `建 表 如无 名 (列, …)` | `CREATE TABLE IF NOT EXISTS 名 (col, …)` |
| 删表 | `删 表 如有 名` | `DROP TABLE IF EXISTS 名` |
| 插入 | `插入 名 (列, …) 值 (?, …), (?, …)` | `INSERT INTO 名 (…) VALUES (…), (…)` |
| 查询 | `选择 列|* 出 名 哪里 … 排序 按 列 升|降 限 n` | `SELECT … FROM … WHERE … ORDER BY … ASC|DESC LIMIT n` |
| 更新 | `改 名 设 列 = ?, … 哪里 …` | `UPDATE 名 SET … WHERE …` |
| 删行 | `删行 名 哪里 …` | `DELETE FROM 名 WHERE …` |

WHERE 条件支持 `=  != <>  >  <  >=  <=`、`和/AND`、`或/OR`、`非/NOT`、括号分组。
值类型：文本（`'单引号'` 或 `"双引号"`）、数、`真/假`、`空/null`、`?` 参数。
排序：默认保持插入顺序；数按数值、文本按 Unicode 码点序（非拼音序，见下 v1.8 增补）。

### v1.8 增补语义

- **自增列**：建表时写 `建 表 名 (编号 自增, …)`。插入时该列不给值或给空值，
  自动取 **全表现有最大值 + 1**（从 1 起），落盘保留——重启后接着编。
- **聚合函数**：`选择 数(*) 出 表`、`和(列)`、`平均(列)`、`最大(列)`、`最小(列)`。
  只算数值，自动跳过空值与文本；不支持 GROUP BY，输出单行。
- **空值比较**：`=` 两边都是空值即视为匹配；`!=` 只是 `=` 的简单取反。
  不是 SQL 的三值逻辑（没有 UNKNOWN）。
- **文本排序**：按 Unicode 码点序（非拼音序，"张"排在"李"之前）。
- **落盘为原子写**：先写临时文件再改名，进程中途挂掉不会写坏库文件；
  每次写操作整库重写一次（教学级规模，入门项目够用）。

### 自增列（v1.8）

建表时给列写 `自增`，插入时不给该列（或显式给 空值）就自动取 全表最大值+1：

```saho
库.执行("建 表 订单 (编号 自增, 客户, 金额)")
库.执行("插入 订单 (客户, 金额) 值 (?, ?)", "甲", 10)   # 编号自动 = 1
库.执行("插入 订单 (客户, 金额) 值 (?, ?)", "乙", 20)   # 编号自动 = 2
```

自增信息随库落盘，重开文件后编号接着排，不会重号。

### 聚合函数（v1.8）

`数(*)` 计数、`和(列)` 求和、`平均(列)` 平均、`最大(列)`/`最小(列)`：

```saho
统 = 库.查询("选择 数(*), 和(金额), 平均(金额) 出 订单 哪里 金额 > ?", 5)
print(统[0]["数"], 统[0]["和"], 统[0]["平均"])
```

聚合只算数（文本/空值跳过）；不带 分组/GROUP BY，永远输出单行；统计维度不同就多查几次。

### 空值与排序语义（v1.8）

- `=` 两边都是空值视为相等（`哪里 金额 = ?` 传 空值 能匹配存了空值的行）；`!=` 是简单取反，不实现 SQL 的三值逻辑。
- 文本比较按 Unicode 码点序（不是拼音序）；数按数值比较。

### 语义约定

- 数值用精确有理数承载，落盘为字符串，永不丢精度。
- 每条写语句成功后**原子落盘**一次（先写临时文件再改名，进程被杀不会留下半个文件）；实现是整库重写，教学规模够用，大库以后再做增量日志。
- `查询` 不允许跑写语句、`执行` 不允许跑选择——报错信息会互相指路。

## 5. 会话落盘与文件上传（v1.8）

- `服务.会话存("会话.json")`：会话写进文件，重启服务不丢；24 小时无活动的会话自动过期（过期的不复活）。
- **文件上传**：表单里带文件（`multipart/form-data`）时，文件自动存进系统临时目录，`请求["文件"]["字段名"]` 是字典：`文件名`、`路径`（临时文件，可直接 读取文件/复制走）、`大小`（字节数）。
- 服务器默认超时：读头 10 秒、读 30 秒、写 60 秒、空闲 120 秒（慢客户端不会挂死服务）。

## 6. 单元测试（测试/assert 模块，v1.8）

给 卅 程序自带的测试写法（不占 30 个内置函数名额）：

```saho
函数 加(a, b)
    返回 a + b
完毕
测试.相等(加(1, 2), 3, "一加二")   # 第三个参数是用例名，可省
测试.为真(长度([1, 2]) == 2)
失败数 = 测试.汇总()               # 打印"通过 X / Y"；全过返回空值，否则返回失败数
```

- `测试.相等(实际, 期望, 名)`：深度相等比较。
- `测试.为真(值, 名)`：值必须为真。
- `测试.汇总()`：打印汇总并返回失败数（0 或空值即全部通过）。
- `测试.清零()`：清空计数（同一进程跑多组测试用）。

## 7. 综合示例：留言板

`examples/留言板.saho`（数据库存留言 + 会话记名字 + 表单提交 + 模板渲染）：

```bash
./sahou.exe run examples/留言板.saho
# 浏览器打开 http://127.0.0.1:8080
```

要点：

- POST 的表单直接读 `请求["表单"]["名字"]`；
- 写 `请求["会话"]["名字"] = 名字`，下次访问输入框自动回填；
- 每条留言先渲染成片段（转义），再以 `[[[留言列表]]]` 原样嵌进外层模板。

## 8. 单元测试（测试/assert 模块，v1.8）

| 成员 | 说明 |
|---|---|
| `测试.相等(实际, 期望, 名)` | 深度相等断言（数、文本、列表、字典都可比） |
| `测试.为真(值, 名)` | 真值断言 |
| `测试.汇总()` | 打印 `通过 X / Y`；全过返回**空值**，否则返回**失败数** |
| `测试.清零()` | 清空计数，重新开始一轮断言 |

```saho
测试.相等(1 + 1, 2, "加法")
测试.为真(长度("你好") == 2, "长度")
失败数 = 测试.汇总()     # 通过 2 / 2
如果 失败数 != 空值
    抛出("有 " + 文本(失败数) + " 个断言失败")
完毕
```

`测试` 是模块、不是内置函数，**不占 30 个内置函数名额**（D9 名额仍是满的）。
